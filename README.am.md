## በAnthropic ተሰላችተናል

ከClaude ጋር መነጋገርና መሥራት እንፈልጋለን፤ ግን VPS፣ የአሳሽ መገለጫዎችና የአካባቢ ፍተሻዎች ማዋቀር ሰልችቶናል፣ የመለያ እገዳና የገንዘብ ኪሳራም ያሳስበናል። **Claude Eden**ን እናቀርባለን — **የዴስክቶፕ የሥራ ቦታ፦ የራስዎን ፕሮክሲ ያዋቅሩ፣ ገለልተኛ አካባቢ፣ የሰዓት ሰቅ፣ ቋንቋና ፍተሻዎችን በአንድ ቦታ ያስተዳድሩ።**

Claude Eden ተርሚናልን፣ አሳሽን፣ አርታዒንና ኦፊሴላዊውን Claude Desktop በWindows ዴስክቶፕ ያጣምራል። የአካባቢ Windows ወይም Linux እንግዳ ይጠቀሙ፣ ወይም የራስዎን Linux ደመና አገልጋይ በSSH ያገናኙ። የመረጡትን ፕሮጀክቶች ያጋሩ፣ አውታረ መረቡን በተናጠል ያስተዳድሩና ከስልክ ይቀጥሉ። የአስተናጋጅ መስፈርቶችና የእንግዳ ችሎታዎች በስርዓት መመሪያው አሉ። ዋና ባህሪያት፦

- ከአስተናጋጁ የተለዩ የአውታረ መረብ ቅንብሮች፤ Claude Eden ሁሉንም የውስጥ ትራፊክ በራሱ ፕሮክሲ ያስተላልፋል
- የሰዓት ሰቅ እና ቋንቋን ጨምሮ ከአስተናጋጁ የተገለሉ የአሳሽ አሻራ ቅንጅቶች ከአውታረ መረቡ ተኪ አይፒ አካባቢ ጋር በራስ ሰር ማመሳሰል
- በClaude የስራ ሂደት ውስጥ ያለው ውህደት፡ የአሳሽ መግባት፣ የመለያ ፍቃድ እና የClaude ኮድ ሂደት
- አብሮገነብ አውታረመረብ እና የመነጠል ፍተሻዎች ወሳኝ ፍተሻዎች ሲቀሩ ወይም ማስረጃው ካልተሟላ የበይነመረብ መዳረሻን ባለበት ያቆማሉ። የማህበረሰብ እና የሶስተኛ ወገን ቼኮች ተጨማሪ የማጣቀሻ መረጃ ይሰጣሉ

## በClaude Eden ምን ማድረግ ይችላሉ

- **በአንድ መስኮት ይስሩ።** Claude Codeን በተርሚናል ያሂዱ፣ ለውጦችን በአርታዒ ይመልከቱ፣ ለቅድመ እይታና ለመግባት Workbench አሳሽ ይጠቀሙ።
- **በሚያውቁት ስርዓት ይገንቡ።** Windows ወይም Linux እንግዳ ይምረጡ። ተስማሚ Windows አስተናጋጅ የስርዓት ስሪትን አዛምዶ ከኦፊሴላዊ ምስል ገለልተኛ አካባቢ ሊፈጥር ይችላል። [የእንግዳ ስርዓት ምርጫ](docs/guide/guest-systems.md)
- **የሚያጋሩትን ይቆጣጠሩ።** ነባሪው የስራ ቦታ እና በግልፅ የተከፈቱ የፕሮጀክት ማህደሮች ብቻ ነው የሚጋሩት። የአስተናጋጁ Claude የመግባት ሁኔታ፣ የአሳሽ መገለጫዎች እና የኤስኤስኤች ቁልፎች በራስ ሰር አይመጡም።
- **የአውታረ መረብ ሁኔታዎን ይመልከቱ።** አብሮገነብ የአውታረ መረብ ተኪ አስተዳደር የደንበኝነት ምዝገባዎችን እንድታስመጣ፣ የመጨረሻ ነጥቦችን እንድትመርጥ እና መውጫውን አይፒ እንድታረጋግጥ ያስችልሃል። ወሳኝ ፍተሻዎች እስኪያልፍ ድረስ አካባቢው ከመስመር ውጭ ይቆያል። የአውታረ መረቡ ተኪ የማይገኝ ከሆነ ቀጥታ ግንኙነት ወደ ኋላ መመለስ የለም።
- **በሚቀጥለው ጊዜ ይቀጥሉ.** መሳሪያዎች፣ ፋይሎች እና የመግባት ሁኔታ በምናባዊ ዲስክ ላይ ይቆያሉ። መስኮቱን ሲዘጉ የበስተጀርባ ተግባራት መሮጥ ይችላሉ።
- **ብዙ የClaude Code መለያዎችን ያስተዳድሩ።** የአጠቃቀም ገደቦችን ይመልከቱ፣ ለአዲስ ክፍለ ጊዜ መለያ ይመድቡ፣ በግልጽ ፈቃድም መለያ ቀይረው ታሪኩን ይቀጥሉ። [Claude Code](docs/guide/accounts.md)
- **ከስልክ ይቀጥሉ።** Android ከኮምፒውተር ጋር በQR ወይም በማጣመሪያ ኮድ ያገናኙ። ተመሳሳይ የClaude Code ውይይቶችን ይቀጥሉ፣ መልእክት ይላኩ፣ መሣሪያዎችን ያጽድቁ እና የርቀት አሳሽን ወይም የኮምፒውተሩን Claude Desktop መስኮት ይጠቀሙ።
- **Claude Edenን በደመና ያሂዱ።** በተስማሚ Linux x86_64 VPS ላይ ካለው Claude Eden ጋር በSSH ይገናኙ፤ KVM አያስፈልግም። ውሂብና የአውታረ መረብ መውጫ በአገልጋዩ ላይ ናቸው።
- **በግል አውታረ መረብ ይገናኙ።** በClaude Eden ውስጥ Tailscale ግቡና በአስተናጋጁና አካባቢው መካከል ባለሁለት አቅጣጫ SSH ይጠቀሙ። [Tailscale / SSH](docs/guide/tailscale.md)

## ፈጣን ጅምር

ይህንን ጥያቄ ወደ AI ወኪልዎ ይላኩ (ኮዴክስ ፣ ዲኤስኤስ ፣ የስራ ጓደኛ - ምናልባት Claude ኮድ 😁 ላይሆን ይችላል)

```markdown
የ https://github.com/CarterLeeAlt/Claude-Eden የቅርብ ጊዜ ኮድ አውርድ፣ ለWindows ገንባና ጫን። የClaude Eden ፕሮክሲ የእኔን የClash xx ኖድና xx IP እንዲጠቀም አዋቅር። መጀመሪያ የግንባታ መመሪያን አንብብ፣ የመጫኛ ወሰንና የአውታረ መረብ ቅንብሮችን አረጋግጥ፣ ከዚያ አስኪድና ውጤቱን ፈትሽ።
```

የሚያስፈልግህ አስተማማኝ የአውታረ መረብ ተኪ የመጨረሻ ነጥብ ነው። ይህ ፕሮጀክት ማንኛውንም ተኪ አቅራቢን አያስተዋውቅም። አቅራቢን እራስዎ ማግኘት ይችላሉ፣ ለምሳሌ የጥቁር ስህተት ድህረ ገጽን በመፈለግ።

## ማውረድ እና መጫን

የClaude Eden ዴስክቶፕ አስተናጋጅ Windows 10 22H2 / 11 x64 ነው፤ Windows 10 ዋናው የቅበላ ሙከራ መድረክ ነው። የአካባቢ እንግዶች Debian፣ Ubuntu 22.04ና Windows ናቸው። Windows እንግዳ Hyper-V ያለው Windows 11 Pro፣ Enterprise ወይም Education አስተናጋጅ ይፈልጋል። የLinux ደመናና የአገልጋይ ክፍልም ይቀጥላሉ። [Windows](docs/windows.md) · [Linux ደመና](docs/linux.md).

1. የታተመ የWindows ጫኚ በ[GitHub Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases) ይፈልጉ። ልቀት ከሌለ [የግንባታ መመሪያ](docs/windows.md) ይከተሉ።
2. የWindows ጫኚውን ያሂዱና **Claude Eden**ን ይክፈቱ። ለአገልጋይ፦ [Linux ደመና](docs/guide/cloud.md)።
3. የራስዎን የአውታረ መረብ ፕሮክሲ ለማዋቀር፣ አካባቢውን ለመጀመር እና ፕሮጀክት ለመክፈት የውስጠ-መተግበሪያ መመሪያዎችን ይከተሉ።

ጫኚው የሥራ ቦታና ፕሮክሲ ያካትታል። Go፣ Node.js፣ Docker ወይም Clash አስቀድሞ መጫን አያስፈልግም። የእንግዳ ስርዓትና ማከማቻ ይምረጡ፣ ኦፊሴላዊ ምስልና መሣሪያዎች ያዘጋጁ። Claude Eden የስርዓት ፈቃድ፣ የፕሮክሲ አገልግሎት ወይም የClaude መለያ አይሰጥም።

ምንጭ ኮድ ለሕዝብ ክፍት ነው። የታተሙ ስሪቶችን ማስታወሻና ቼክሰም በ[Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases) ይመልከቱ።

ባህሪያት በሚጠቀሙት ግንባታ ይወሰናሉ፤ የሕዝብ መጫኛው ችሎታና የሙከራ ወሰን በልቀት ማስታወሻ ይገለጻሉ።

የተፈረሙ Windows ስሪቶች በተመረጠው ፕሮክሲ ይዘምናሉ። ያልተፈረሙ ግንባታዎች በጫኚው በእጅ ይዘምናሉ። መጀመሪያ ሥራን ያስቀምጡና ያቁሙ፤ የግል ውሂብ ይጠበቃል። [ማዘመን እና ማስወገድ](docs/guide/maintenance.md)

## በሶስት ደረጃዎች ይጀምሩ

### 1. የአውታረ መረብ ተኪ ይምረጡ

በመነሻ ገጹ ላይ 'ኔትወርክን እና ፕሮክሲን አዋቅር'፣ በመቀጠል 'ምንጭ አክል' የሚለውን ጠቅ ያድርጉ። የክላሽ/ሚሆሞ YAML ደንበኝነት ምዝገባን ወይም የአካባቢያዊ YAML ፋይል አስመጣ እና በ'Nodes' ስር ያለ የመጨረሻ ነጥብ ምረጥ። ምንም የአውታረ መረብ ተኪ ከሌለ፣ 'ይህንን የደንበኝነት ምዝገባ በአስተናጋጅ አውታረመረብ አውርድ' የሚለውን በግልፅ መምረጥ ወይም የአካባቢ ፋይል በቀጥታ ማስመጣት ይችላሉ። በኋላ፣ የመጨረሻ ነጥቦችን በ'Settings → Network and proxy' ስር ያስተዳድሩ።

### 2. አካባቢውን ይጀምሩ

መጀመሪያ የእንግዳ ስርዓት፣ ወይም ሲደገፍ ራስ-ሰር የስሪት ማዛመድ፣ እና ማከማቻ ይምረጡ። እንግዳውን ይጫኑ፣ አካባቢውን ያስጀምሩና ፈቃዶችን ይስጡ። ሂደትና ስህተቶች በሥራ ዝርዝር ይታያሉ። ቀጣይ ጅማሬዎች ያንኑ አካባቢ ይጠቀማሉ።

### 3. ፕሮጀክት ይክፈቱ እና Claude ያሂዱ

'Open Project' በመጫን ማህደር ይምረጡ፣ ተርሚናል ይክፈቱና `claude` ያሂዱ። መለያዎን በWorkbench አሳሽ ያጽድቁ። በነባሪው የሥራ ቦታም መጀመር ይችላሉ። ሙሉ ደረጃዎች፦ [በመጀመር ላይ](docs/getting-started.md)።

## ከመጠቀምዎ በፊት እነዚህን ገደቦች ይረዱ

- በጋራ ፕሮጀክቶች የሚደረጉ ለውጦችና ስረዛዎች የኮምፒውተር ፋይሎችን በቀጥታ ይነካሉ። የስሪት ቁጥጥር ወይም ምትኬ ይጠቀሙ። `.git` ማንበብና መጻፍ ይቻላል፤ በClaude Eden stage፣ commitና branch መቀየር ይቻላል።
- በአንድ Claude Eden ውቅር ያሉ ፕሮጀክቶች እንግዳ፣ መሣሪያ፣ መለያና ፋይል ስርዓት ይጋራሉ፤ አንዱ ከሌላው አይገለልም። ስርዓት መቀየር የተለየ መጫን ይፈልጋል፤ የቀድሞው አካባቢ ውሂብ ይጠበቃል።
- በነባሪ የውጭ አውታረ መረብ IPv4 TCP ይደግፋል፣ DNS በዚያው ፕሮክሲ ይላካል። የሕዝብ UDP፣ IPv6፣ ICMP እና ቀጥታ ወደ አስተናጋጅ ወይም LAN ግንኙነት የተገደቡ ናቸው። Tailscale በግልጽ ሲነቃ የመሣሪያ ግንኙነት የግል አውታረ መረቡን ፈቃድ ይከተላል።
- የአውታረ መረብ ፍተሻዎች የአሁኑን ውቅር እና የናሙና ማስረጃዎችን ያሳያሉ። መለያ የመድረክ ገደቦችን እንደሚያስወግድ ዋስትና ሊሰጡ አይችሉም እና የተሟላ የቨርችዋል ሴኪዩሪቲ ኦዲትን አይተኩም።

ለዝርዝር መረጃ ይመልከቱ [የአውታረ መረብ እና የውሂብ ገደቦች](docs/getting-started.md#网络与数据边界).

## ማጣቀሻዎች እና ምስጋናዎች

ለመሠረታዊ ችሎታዎች እና የንድፍ ማመሳከሪያዎች ለሚከተሉት ፕሮጀክቶች ምስጋና ይግባው.

- [agent-vm](https://github.com/sylvinus/agent-vm)፦ የፕሮጀክቱ መሠረት።
- [Lima](https://github.com/lima-vm/lima) የሊኑክስ ምናባዊ ማሽን አስተዳደር.
- [gvisor-tap-vsock](https://github.com/containers/gvisor-tap-vsock): ምናባዊ ማሽን አውታረ መረብ.
- [sshocker](https://github.com/lima-vm/sshocker) እና [SFTP](https://github.com/pkg/sftp) በቨርቹዋል ማሽን እና በአስተናጋጅ መካከል የፋይል መጋራት።
- [noVNC](https://github.com/novnc/noVNC) በአሳሹ ውስጥ የርቀት ማሳያ እና መስተጋብር።

- [code-server](https://github.com/coder/code-server): በአሳሽ ላይ የተመሰረተ ኮድ አርታዒ.
- [AIO Sandbox](https://github.com/agent-infra/sandbox) የሥራ አካባቢ እና መስተጋብር ንድፍ ማጣቀሻዎች.
- [claude-switcher](https://github.com/YOURSJEYO/claude-switcher) እና [Claude-Guardian](https://github.com/DUNHKpcc/Claude-Guardian) ለአውታረ መረብ ፍተሻዎች እና የደህንነት ምርመራዎች ማጣቀሻዎች።
- [claude-post-ban-cleanup](https://github.com/l2461090/claude-post-ban-cleanup): ለትክክለኛ ቆጠራ፣ ለውሂብ ጥበቃና ሊመለስ ለሚችል የመሸጎጫ ማጽዳት ማጣቀሻ፤ በClaude Eden በተናጠል ተተግብሯል።
