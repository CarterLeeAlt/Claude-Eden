## 登录并加入私网

侧栏“浏览器”下方的“Tailscale”将当前 Workbench 环境作为独立设备加入私网。登录状态保存在客机磁盘，切换页面后仍连接。本机、手机或服务器也需安装 Tailscale 并加入同一网络。

启动环境，在“Tailscale”选择“连接并登录”。Claude Eden 打开官方授权页，完成后返回设备清单。浏览器询问是否打开应用时确认即可。连接成功后显示账号、网络名称、当前环境私网地址和设备清单。需要设备审批时显示“等待管理员批准”，由网络管理员批准对应设备。

Google 登录提示浏览器或应用不安全时，核对 Claude Eden 与环境组件版本，按面板提示重新发起登录。浏览器启动设置需重启环境生效；网页登录状态与设备身份保存在原数据中。

Debian 环境首次使用时点击“安装 Tailscale”。Windows 随客机组件提供。已安装的 Tailscale 随组件更新，设备身份和 SSH 公钥保留；尚未安装时按需安装。

设备清单显示私网允许当前环境发现的设备，在线设备排在前面，可按名称、系统或地址搜索。为空时检查其他设备是否加入同一网络及其访问规则。

## 使用设备上的服务

在设备旁点击「使用设备」，按服务类型选择连接方式。设备在线表示它已连接 Tailscale，服务是否可用仍取决于目标设备是否启动该服务、端口和访问权限。

### Web、数据库与其他 TCP 服务

例如开发网站监听 `8080`：填写服务端口并点击“创建连接地址”。面板给出类似 `127.0.0.1:32123` 的地址，客机应用通过它连接目标服务。HTTP 网站可点击“打开 HTTP 页面”，数据库等客户端按目标要求认证。

这些地址只在当前客机内生效。HTTPS 和需要目标域名与证书一致的服务，使用下述私网代理保留原域名与证书校验。

### 需要设备域名、HTTPS 或多个端口的应用

展开“应用访问私网”，复制代理地址，配置为需要访问私网的客机应用的 HTTP 代理。它支持 HTTP 和 HTTPS CONNECT，只连接私网中可见的设备；公网访问仍使用原公网代理。

复制的地址包含本地访问凭据，不要分享给他人。组件进程重启后需重新复制代理地址。

Workbench 使用内嵌 Tailscale 节点。SSH 自动配置私网传输，其他应用通过本地连接地址或 HTTP 代理访问 TCP 服务。系统 VPN、UDP、子网路由和出口节点未启用，宿主机的 Tailscale 与系统网络独立管理。

### 从环境 SSH 到其他设备

目标设备需开启 SSH 服务。填写目标系统用户名，复制 SSH 命令并在工作台终端运行，使用目标服务接受的密码或密钥认证。宿主机私钥需由用户明确提供。

普通 `ssh`、SFTP 和 OpenSSH 工具可使用设备的私网 IPv4、完整名称或短名称。Workbench 为已发现设备维护专用传输配置，保留用户原规则。

## 从其他设备 SSH 到环境

需要远程终端、SFTP 或编辑器连接时，展开设备接入面板，添加连接设备的一条 SSH 公钥，私钥保留在原设备。面板不接受私钥或带限制选项的 `authorized_keys` 条目。

复制面板给出的命令，在连接设备的终端运行，例如：

```sh
ssh <面板显示的用户名>@100.88.2.3
```

首次连接核对并保存服务端指纹。登录后拥有当前客机普通用户权限，可使用交互终端、远程命令、SFTP 和本地端口转发。移除公钥拒绝新连接，断开 Tailscale 结束已有私网连接。

这里使用标准 SSH 公钥认证。Tailscale 专用的「Tailscale SSH」身份认证需另行配置，登录 Tailscale 本身不自动授予系统 SSH 权限。

## 断开、退出与数据保留

「断开连接」结束私网连接与服务映射，保留登录状态、公钥和 SSH 服务端身份。重新连接沿用原设备；本地服务地址需要重新创建。「退出登录」撤销当前登录，下次连接需要浏览器重新授权，已添加的 SSH 公钥保留。

私网外层通信经过 Claude Eden 的受控出口，公网 UDP 受限时使用中继。暂停联网、代理中断、环境停止或后台退出会影响连接。环境重新启动后恢复已启用的 Tailscale 身份。

设备间访问仍受 Tailscale 网络规则控制。连接到其他设备后，命令的权限和网络行为由目标设备管理。
