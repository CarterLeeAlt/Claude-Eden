## 导入自己的代理

入口是首页“配置网络与代理”，或“设置 → 网络与代理”。点击“添加来源”，选择导入方式：

| 来源 | 怎么填 |
| --- | --- |
| 订阅链接 | 输入名称和 HTTPS 节点订阅地址。首次没有可用节点时，可明确勾选“通过主机网络下载这份订阅”。 |
| 本地 YAML | 拖入或点击选择导出的 YAML、YML、JSON 文件（单个不超过 8 MiB），也可直接粘贴 Clash/Mihomo YAML 内容。读取后可编辑，点击“导入并验证”完成导入。 |
| 手动节点 | 选择 HTTP、SOCKS5 或 SSH，填写服务器、端口和认证信息。SSH 默认端口为 22，用户名必填；可选择密码或私钥认证。私钥认证须粘贴完整私钥内容，加密私钥还需填写私钥口令。 |

点击“导入并验证”，进入“节点”，选最终出口，再点“应用代理”。“保存设置”用于其他设置，不能替代应用代理。未应用的选择只是草稿。

订阅必须包含 `proxies` 或 `payload` 节点。Base64 列表、单个节点分享链接、只引用远程 provider 的配置暂不支持。导入只采用支持的节点与代理链，不采用订阅中的主机系统代理、TUN、监听端口或直连规则。

普通节点参数交给 Claude Eden 随附的 Mihomo 核心校验。例如，VLESS 节点可保留 `xudp: true`。内核可能忽略未知字段；校验通过后仍需应用节点并检查出口。客机公网 UDP 阻断规则不受这些协议选项影响。

VMess、VLESS 和 Trojan 的 WebSocket 节点可导入服务商使用的 `ws-path`、`ws-headers`。节点须设置 `network: ws`，Claude Eden 将其转换为核心字段 `ws-opts.path`、`ws-opts.headers`。两种写法共存时路径须一致，请求头按名称合并且忽略名称大小写。值冲突、重复字段或传输方式不符时，来源显示原因，修正节点后重新导入。

Hysteria2 节点可使用 `mport` 指定端口跳跃范围、`pinSHA256` 指定证书指纹，导入时会转换为核心支持的字段并保留功能。若节点使用不支持的协议、引用本机文件或网卡、管理字段重复、别名参数冲突或代理链不可用，会跳过该节点，并在来源下显示导入数量、跳过数量和原因。点击「查看原因」可展开具体节点；依赖失败节点的代理链也会跳过。若所有节点均被跳过，导入失败；更新影响当前出口或中转节点时保留原配置，请先应用其他节点再更新。其余节点还须整体通过核心配置校验，校验失败时原配置保持不变，可在设置的「日志与诊断」中导出诊断包查看校验记录。

手动添加 SSH 节点时，可在“服务器公钥”中填写可信公钥，每行一条；留空时不校验服务器身份。

SSH 节点（`type: ssh`）可以把自己的 VPS 直接作为固定出口，服务器上只需开启 SSH，无需另外部署代理服务。可用 `password` 或 `private-key` 认证；`private-key` 须直接填写 PEM 私钥内容（含 `-----BEGIN ... PRIVATE KEY-----`），引用本机私钥文件路径的节点会被跳过，加密私钥可配合 `private-key-passphrase`。建议用 `host-key` 固定服务器公钥（`ssh-keyscan` 输出中的 `ssh-ed25519 AAAA...` 部分），未填写时核心不校验服务器身份。SSH 节点仅转发 TCP。示例：

```yaml
proxies:
  - name: my-vps
    type: ssh
    server: 203.0.113.10
    port: 22
    username: root
    private-key: |
      -----BEGIN OPENSSH PRIVATE KEY-----
      ...
      -----END OPENSSH PRIVATE KEY-----
    host-key:
      - "ssh-ed25519 AAAA..."
```

同一订阅地址可能按客户端身份返回不同格式。Claude Eden 使用 Clash 客户端身份下载；服务商返回 YAML 时可导入，返回其他格式时向服务商获取 Clash/Mihomo YAML。

## 通过中转连接住宅出口

如果住宅节点无法直接连接，在“节点”页切换到“链式代理”。按连接顺序选择中转，将住宅节点设为“最终出口”；需要多次中转时点“添加中转”。节点可以来自不同来源。

应用前检查预览，例如：`Claude Eden → 中转节点 → 住宅代理 → 目标网站`。目标网站看到最终出口。订阅更新保留已保存组合；正在使用的节点被移除时保留原配置并提示重新选择。

## 为什么应用了节点仍然离线

代理核心就绪和工作环境获准联网是两个步骤。环境启动后先保持业务外网关闭，执行出口、DNS、系统与浏览器配置、共享目录、宿主管理接口和网络阻断等关键检查。Linux 客机的 DNS 项同时要求解析器只指向环境内地址，且到公共 DNS 的 UDP/53、TCP/53 与 DoT/853 直连未绕过网关；宿主管理接口项还探测链路本地元数据地址和已配置的用户代理端口。IPv6 项要求客机全局 IPv6 地址为零，并核对路由或拒绝记录。缺少探针结果时显示未知；任一关键项失败或证据缺失都会继续关闭外网。

出口检测通过所选代理读取公网 IPv4 地址，依次使用 `https://ipv4.icanhazip.com/` 和备用服务 `https://api.ipify.org/`。双栈节点使用其 IPv4 出口完成检查；宿主、客机终端和浏览器使用相同的检测方式。启动检查无法取得有效地址时，业务外网保持关闭，可稍后重试或检查节点。

点击底部网络状态查看失败项，修复后重新检查。核心运行但环境未启动时会显示“待启动环境”。关键检查通过、联网授权有效时才显示“已联网”。

“出口采样不完整”会列出未取得结果的路径：宿主、虚拟机终端或浏览器，以及超时、检测通道返回的 HTTP 状态或缺少地址等原因。终端代理检查通过只证明该次终端采样成功，宿主和浏览器仍须分别取得结果。动态 IP 规则决定哪些出口地址可以接受，采样失败时仍须重新检测。

浏览器出口采样没有响应或返回 HTTP 503 时，Claude Eden 等待一秒并重试一次。期间外网保持关闭；持续失败保留最后结果。配置不符或缺少出口地址时先处理对应失败项。环境就绪而联网检查未通过时，可直接重检网络。

离线时可使用终端、共享文件及环境内服务。Workbench 浏览器的 `localhost` 指当前客机；开发服务在工作台终端启动。

## 系统镜像的下载网络

系统镜像与版本目录使用主机网络，与客机代理节点分开。Clash 等软件的系统代理可以接管这些下载。Claude Eden 遵循主机对下载网站的代理规则，主机未配置代理时访问官方源。

- Windows：读取当前用户的系统代理；PAC 与自动检测通过 WinHTTP 按目标地址解析。
- Linux 云端：使用服务器配置的代理环境变量或已有网络通道。

从终端启动时，目标协议对应的 `HTTP_PROXY`、`HTTPS_PROXY` 优先于系统设置，`ALL_PROXY` 作为缺省代理，并遵循对应的 `NO_PROXY` 例外。这些主机设置不会传入客机。代理连不上或已配置的 PAC 解析失败时，下载停止，不因失败切换直连；修复主机代理后，在初始化界面继续安装，已有下载会尝试续传。

系统镜像和开发工具优先使用官方源。Debian 镜像下载失败后尝试提供同一固定版本的国内镜像；Debian 软件源和 Linux 工具在官方源不可用时尝试备用镜像。各下载路径保留原有的摘要、软件包签名或应用签名检查，自定义 Debian 软件源保持原样。

客机进程和客机内工具下载使用 Claude Eden 的独立代理。镜像下载后仍需完成客机网络与隔离检查。

## 时区、语言与出口规则

在“设置 → 时区与语言”选择跟随出口或手动设置。自动模式通过代理查询出口位置，不使用主机位置替代。位置服务失败时可重试或切换节点；手动设置时区和语言仍须确认出口国家或地区。

网络页的“IP 变化规则”按最终出口节点保存，支持静态 IP，以及动态 IP 的同一城市、同一州／省、同一国家／地区或不限地区。城市模式还检查国家与州省。切换最终出口时自动恢复该节点的规则；首次使用的节点沿用当前的静态或动态模式及允许范围，通过代理检测并确认非中国大陆出口后绑定自己的 IP 或地区。仅更换中转、刷新订阅、重新检查或重启会保留该节点的基准。

例如，住宅节点001与节点003分别绑定各自的固定 IP，来回切换会自动使用对应地址；同一住宅节点意外更换 IP 时仍会暂停外网，需要确认后明确修改。旧配置未记录出口基准所属的节点时，原规则持续生效，直到明确应用节点后为其检测并建立绑定。

中国大陆出口禁止放行。检测地址命中内置大陆网段库，或定位结果为中国大陆时，业务外网保持关闭；静态 IP 和“不限地区”均不能豁免。无法确认出口国家或地区时也保持关闭，离线终端和文件仍可使用。地区定位和网段库可能存在误差；后台按周期采样，无法保证第三方代理每条连接都使用同一出口。

保存影响系统环境的配置可能要求重启。先保存文件；运行中不会因后台发现位置变化而静默重启任务。

## 暂停、恢复和网络切换

点击底部状态可手动暂停外网，切断外部连接并保留本地任务与文件操作；关闭、重开 Claude Eden 或刷新订阅会保留手动暂停状态。

后台定期核对出口与环境配置。两个检测服务均超时时，Claude Eden 在原联网许可到期前重试；到期未确认则关闭外网并完整复检。出口或配置不符时立即暂停。主机切换网络后尝试完整复检，手动暂停仍需主动恢复。控制服务失联后，网络许可到期关闭。固定出口还依赖代理服务，周期采样不能证明所有连接使用同一 IP。

自动完整复检首次在 15 秒后尝试，失败后依次等待 30、60、120、240 秒，之后每次等待 300 秒；实际开始时间还取决于环境就绪、当前操作和内存压力。网络状态会显示剩余等待时间或等待原因。重新检查必须取得全部关键证据，自动恢复不会修改已保存的出口规则。

## DNS 与诊断

业务 DNS 通过所选代理转发，节点域名的启动解析属于独立的准备通信。Claude Eden 仅管理自身代理，主机系统代理、TUN 和其他代理节点保持其原有配置。

代理页“诊断”可检查核心状态、重启 Claude Eden 核心或选择独立端口。端口占用时选择空闲端口，并按提示重启环境。见[故障排查](troubleshooting.md#节点已应用但无法联网)。

## 通过 Tailscale 私网使用 SSH

从侧栏“浏览器”下方打开“Tailscale”，在 Workbench 浏览器授权后，可通过私网双向 SSH。连接步骤、公钥和本机 SSH 服务要求见 [Tailscale 与 SSH 私网](tailscale.md)。

私网访问由用户启用，受设备和 SSH 授权约束。外层通信经过 Claude Eden 受控出口，暂停外网或代理中断会影响连接。它与主机、局域网直连分别处理，使用专用私网通道。
