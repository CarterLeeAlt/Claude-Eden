## 安装与登录

Claude Desktop 运行在所选 Linux 环境内。Windows 10 工作台提供安装、打开、显示和关闭入口，应用数据留在 Linux 环境。见[选择客机系统](guest-systems.md)。

在侧栏点击“Claude Desktop”，首次选择“下载并安装”。启动环境并确认代理可用后，Claude Eden 从 Anthropic 官方源安装；下载失败可查看进度并重试。维护下载可在业务外网尚未放行时进行，应用联网仍需关键检查通过。

首次登录在环境内完成。登录和外部网页在 Workbench 浏览器打开，回调后返回 Desktop；若停留在浏览器，可从侧栏返回应用查看。

Chat 和 Code 在同一个官方应用内使用。需要额外虚拟机的 Cowork 暂不支持。手机可以接续电脑上的同一个 Desktop 窗口，两端共用账号与应用数据，见[手机操作 Claude Desktop](mobile.md#在手机操作-claude-desktop)。

## 调整文字与画面

右上角“显示大小”默认 100%，调小可显示更多内容，调大可放大文字和控件。窗口、侧栏变化时画面自动适配；设置保存在本机。提示“画面尺寸未能同步”时点“重试调整”。

Linux 环境的 Desktop 画面在无人操作时降低刷新率，操作时恢复 60 Hz。新配置默认使用 2 倍像素渲染；“显示大小”改变文字和控件大小，渲染密度由下述偏好控制。详见[浏览器说明](browser.md#打开网页与浏览器设置)。

“优先流畅”默认关闭。开启并保存后，下次启动以 1.5 倍像素渲染，控件逻辑大小保留；关闭后恢复 2 倍。性能还受主机 CPU、内存和远程网络影响。

## 复制与粘贴

使用 Linux 客机时，Claude Eden 在环境运行期间共享本机、Workbench 浏览器和 Claude Desktop 的剪贴板。复制消息或选中文字后可在本机粘贴；本机文字、图片、文件和文件夹也可传入客机。切换画面后继续同步，锁定账户、切换环境或退出工作台时结束旧连接。

文字最多 2 MB，图片最多 20 MB、4000 万像素；一次最多选择 100 个文件或文件夹，每个普通文件最多 2 GB。文件传递保留原名与目录结构，来源文件继续保留，跨环境的文件剪切按复制处理。接收文件或图片仍需要目标应用支持该类粘贴。普通网页入口受浏览器权限限制，无法自动共享时可使用原有复制、粘贴和文本传递入口。

## 选择项目与传文件

Desktop Code 请求选择目录时，Claude Eden 显示“选择工作项目”。选择已授权项目并点“使用此项目”，或用“添加本机项目…”新增目录。改动直接作用于共享原件。

网页或 Desktop 上传附件时，点“选择本机文件”调用系统窗口。也可将文件拖入支持附件的区域，或在选中附件输入位置后粘贴。详细数量、大小及保留规则见[上传与附件](workbench.md#上传下载与附件)。

本机模式下，打开与定位只接受已授权项目或已保存下载记录中的文件。Linux 客机与 Windows 主机之间的文件传递仍需在当前改名构建完成完整实机验收；没有主机保存成功记录时，先核对客机文件与操作详情。云端文件按远端下载流程保存到本机。

## 关闭、更新与恢复

切换到终端或浏览器时 Desktop 保持运行。应用上方的“关闭应用”释放其运行资源，登录资料继续保留。

Linux 版由 Anthropic 官方 apt 源更新。在工作台 Desktop 顶部点击“更新应用”，保存工作后确认，程序关闭应用、安装可用版本并重新打开。关闭后也可选“更新 / 修复安装”。需要终端操作时，先关闭 Desktop，再在客机终端运行：

```sh
sudo apt update
sudo apt install --only-upgrade claude-desktop
```

安装完成后从侧栏重新打开 Desktop。使用相同软件源重复更新会保留当前已安装版本。Linux 更新方式见 [Anthropic 安装说明](https://support.claude.com/en/articles/10065433-install-claude-desktop)。

Workbench 组件为内部系统密钥环创建和解锁凭据，无需另设密钥环密码。修改 Claude Eden 密码会保留 Desktop 登录数据。

Desktop 的 Code 授权通过内部系统密钥环加密保存，关闭并重新打开应用后继续使用。若旧授权已经失效，仍需在 Desktop 中重新登录一次；官方要求重新授权时，应用也会显示登录提示。

更新 Claude Eden 或环境组件后，保存工作、关闭并重新打开 Desktop，让文件选择、缩放等组件生效。画面或上传异常时，查[故障排查](troubleshooting.md#浏览器desktop-或文件上传异常)。
