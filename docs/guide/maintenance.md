## 数据保存在哪里

便携版的配置、私有数据密钥、日志、缓存、下载和持久虚拟磁盘均位于程序目录内的 `data/`，备份与移动必须保留整套数据。非便携模式的默认配置根为用户主目录下的 `.eden`，环境位置以实际配置为准。本机共享项目仍在原项目目录；不能只保存账户文件或单独的虚拟盘。

## 环境清理

入口：“设置 → 环境与恢复 → 环境清理”。操作只作用于当前选中的 Linux 工作环境，需要先启动环境。

1. 点击“只读盘点”。Claude Eden 查看允许清单内缓存的大小、文件数量，以及账户、网站登录和会话存储等受保护位置是否存在。盘点不写入环境，也不读取凭据、Cookie 值或会话正文。文件存在状态不能判断是否已登录，以账户页和客户端实际显示为准。
2. 勾选可清理项，点击“清理所选缓存”，核对确认框中的项目与大小。预览有效期为 10 分钟，执行前会重新核对进程和文件状态；缓存变化后需重新盘点。
3. 查看结果。选定缓存移入环境内的私有恢复批次，原权限与内容保留。运行中的相关客户端、链接、挂载点、未知或不可访问目录均保留。不会强制关闭应用、终端或任务。
4. 需要撤销时，在同一面板找到“缓存恢复批次”，点击“恢复此批缓存”。原位置已有新文件或客户端正在运行时，该项保留恢复副本并说明原因，不覆盖新数据。

清理范围仅包含已知位置的 Claude Code `cache`、浏览器及 Claude Desktop 的 `Cache`、`Code Cache`、`GPUCache`。账户配置、登录凭据、钥匙串、Cookie、网站存储、会话、项目、技能、插件、浏览器历史与持久磁盘均不清理。没有发现某项缓存时不会创建它；相关应用仍在运行时，对应缓存会保留，关闭网页标签不一定结束浏览器进程。

恢复副本仍占用空间，不会自动删除，因此清理完成不代表已释放磁盘空间。缓存可由客户端重新生成，首次加载可能稍慢。中途失败或连接中断后，保留原文件与恢复记录，重新盘点查看已完成的批次；不要直接重放旧清单或删除恢复目录。

盘点、清理和恢复均由 Claude Eden 内置程序执行，无需 Agent。打开设置、启动环境和后台运行都不会自动盘点或清理。该功能用于本地缓存维护，不改变账号状态或承诺解除平台限制。

盘点、保护资料与可恢复处理的流程借鉴了 [claude-post-ban-cleanup](https://github.com/l2461090/claude-post-ban-cleanup) 和 [Claude-Guardian](https://github.com/DUNHKpcc/Claude-Guardian)。感谢社区项目提供参考；Claude Eden 根据自身多账户与客户机边界独立实现，未集成其账户重置、ID 轮换或整机环境修改脚本。

## 迁移环境到另一块磁盘

便携版不提供将虚拟磁盘单独迁到包外的操作。保存工作、停止客机并退出，然后移动整个程序文件夹，保留完整 `data/`；外部项目授权不会自动映射到另一台电脑的同名目录。

以下独立环境迁移仅适用于非便携模式，入口：“设置 → 环境与恢复 → 本机环境存储”。

1. 保存编辑器和终端中的工作，选择本地磁盘上的专用空目录。不要选盘根目录、网络盘、程序目录、配置目录或项目目录。
2. 确认迁移。Claude Eden 会停止环境和终端，复制并校验数据，成功后切换存储路径。
3. 手动启动环境，核对文件、浏览器登录和工具。
4. 确认正常后，再通过面板清理本次迁移显示的旧备份。旧缓存可能供其他 Lima 实例使用，会留在原位置。

目标盘须有足够空间并支持权限和稀疏文件。外接盘以后每次启动前都要接回；找不到磁盘时先连接原盘，不要新建环境覆盖状态。

## 设置 CPU 与内存

入口：“设置 → 环境与恢复 → 计算资源”。自动内存上限取主机份额与 8 GiB 的较小值，CPU 按主机份额分配。需要手动控制时关闭“自动分配资源上限”，在页面允许范围内填写内存 GiB 和逻辑 CPU 核心数；手动内存可使用完整主机份额。

点“保存资源配置”后下次启动生效。运行中可“重启并应用已保存配置”，先保存工作，重启会结束正在执行的命令。内存可以在上限内按需增长与回收，设置上限不会使所有内存一直占满。

一般内存压力下分步增加，严重压力时恢复到上限；空闲时每步回收多余量的四分之一，至少 256 MiB。

任务退出 137 时结合 OOM 计数和诊断判断，避免只凭退出码认定内存不足。

## 区分三种更新

| 更新对象 | 在哪里操作 | 影响 |
| --- | --- | --- |
| Windows 桌面应用 | 应用更新入口，或下载完整安装包手动替换 | 安装会结束相关环境与终端；保留持久数据。 |
| 环境组件 | 设置 → 环境与恢复 → 版本与组件 → 更新环境组件 | 可能重启浏览器和编辑器。工作台独立终端通常保留，编辑器内终端可能结束。 |
| 环境工具 | 同页“更新环境工具” | 按当前应用指定版本更新工具，需要环境就绪；先更新不兼容的组件。 |

操作前保存工作。替换 App 不代表持久环境中的所有组件已经更新，看到版本不匹配时按页面同步。环境组件与工具维护下载经过所选代理，手动暂停业务外网不会被维护操作解除。

便携候选尚未完成自动更新验收，不要用安装器覆盖其目录。更换程序前停止客机并退出，备份并保留完整 `data/`。下文安装器交接与回滚只说明安装器模式。

桌面应用的更新检查和安装包下载优先使用主机网络，遵循系统代理及主机代理环境变量；主机连接失败或等待响应超时后再尝试 Claude Eden 所选代理。主机已收到的版本不存在、访问拒绝或限流响应会直接显示，限流提示中的等待时间继续有效。下载开始后若传输中断，可在原入口重试。

Windows 自动安装需要可信 Authenticode 签名和相同发布者公钥。未签名 Windows 预览版使用完整安装包手动更新。自动更新下载失败可在原入口重试。

Windows 自动安装失败时，会先核对原程序是否完整；原程序完整时直接重新打开，已经替换且新版无法就绪时尝试恢复原程序。恢复会保留项目的最新内容、账户、配置、登录凭据和持久磁盘。若个人文件的迁移或恢复尚未完成，程序会保留备份与事务回执并停止自动启动；此时不要删除这些材料或重复覆盖安装。

## 恢复配置与导出诊断

“恢复上一份配置”会先停止环境，再恢复上一次保存的配置。它不能恢复已结束的命令，也不能还原项目文件修改。运行前阅读页面提示并保存内容。

同页的日志诊断可导出 ZIP。应用界面无法使用时，也可按[故障排查](troubleshooting.md#导出诊断与反馈)从命令行导出。默认日志保留 14 天，总预算 50 MiB，不以此替代自己的数据备份。

## 备份、重装与卸载

先保存文件，停止环境和相关后台，再备份完整配置根、选择的环境存储与共享项目。完整备份需要保持同一时点的一致性；运行中的进程和临时终端输出不能靠磁盘备份恢复。

便携版删除整个目录也会删除其中的 `data/`，不能视为“只卸载程序”。需要保留资料时先停止客机并完整备份数据。非便携安装器卸载只管理应用文件，个人数据继续保留；再次安装使用原配置与数据路径。换机器、回滚或手动迁移前，核对账户密钥、收藏、密码库和持久磁盘能一起恢复。

需要彻底清理时，先保存程序目录中的 `Eden.cleanup.md` 和 `Eden.install-files.json`。前者列出当前构建的宿主程序、配置、缓存、注册表、本地 Debian 13 虚拟机与客机 Tailscale 资源；后者记录包内文件的 SHA-256。请让协助清理的 AI 先读取清单，解析实际配置路径、存储迁移记录和设备身份，再按你批准的数据范围处理。清单本身会随正常卸载移除，因此应在卸载前另存。

清理本软件的私有数据后，用户项目、主动保留的下载、共享 WebView2／系统组件及操作系统审计记录仍可能存在。清单写明这些资源的归属和核验方法；不能以删除其他软件的数据或清空系统日志来判定本软件卸载完成。

Windows 安装器会保留程序目录内的已有项目、文件和链接。与新版程序同名的修改文件，以及程序装载目录中无法确认归属的旧可执行库，保存在安装目录的 `Eden-preserved-files` 子目录。安装期间出现的额外修改也可能保存在该目录的 `late-` 子目录中。卸载后若仍有个人文件，安装目录会继续保留，再次安装可以沿用这个目录。

Windows 安装恢复被文件占用或路径冲突阻断时，安装目录旁会保留同名的 `.eden-installation.json` 回执，其中记录原安装、候选和备份目录。请保留回执及记录的目录，按报错定位个人文件后再恢复。自动更新会停止启动未完成恢复的应用。

备份还需覆盖 Debian 13 客机的完整身份，虚拟机配置与系统盘应一并保存。见[持久数据](guest-systems.md#持久数据)。

恢复前保留原件与备份，不用初始化用户数据或删除虚拟磁盘解决更新失败，遇到原账户消失先查[数据目录](troubleshooting.md#原账户与数据看不见了)。
