## 选择安装包

从 [GitHub Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases) 查看实际发布的 Windows 安装包、签名和校验文件。没有公开安装包时按[Windows 构建说明](../windows.md)从源码构建；源码压缩包不能直接安装。

| 平台 | 要求与安装方式 |
| --- | --- |
| Windows 桌面 | Windows 10，当前构建为 x64。便携版解压后运行 `ClaudeEden.exe`，无需安装器或 CMD；本机 Linux 客机使用 Windows 虚拟机监控程序平台（WHPX），启用后按系统要求重启。实际验收范围见[当前版本状态](../current-status.md)。 |

使用链固定为 Windows 10 主机运行本地 Debian 13 客机。依赖详情见 [Windows 指南](../windows.md#windows-版本与功能范围)。

首次创建时，程序下载并校验 Debian 13 官方镜像。镜像与存储说明见[Debian 13 客机](guest-systems.md)。

## 可选的 ClaudeEden 本地账户

新装直接进入初始化，不要求本地账户或密码。只有主动启用密码保护时才需要创建账户；以下密码、记住登录和恢复密钥说明仅适用于已启用的账户。Claude 订阅仍需在客机内另行登录。注册密码账户后保存恢复密钥，见[账户恢复](settings.md#保存恢复密钥)。

无账户模式使用持久私有数据密钥；应备份完整 `data/`，不要删除其中的密钥文件。主动创建密码账户会保留现有加密数据。密码账户的本机信任条件见[受信任的本机登录](../getting-started.md#受信任的本机登录)。

完整桌面版创建密码账户时默认勾选“记住我”，可取消；已有账户可在登录页或“设置 → 账户”调整。手动锁定后仍需验证，退出账户会撤销快捷登录授权。账户密码不会加密整个项目目录或虚拟磁盘。

若以前已有账户，现在再次出现创建页面，先停止操作并查[数据目录问题](troubleshooting.md#原账户与数据看不见了)。

## 初始化系统与存储

首次打开显示独立初始化界面，系统固定为 Debian 13，程序下载官方镜像并安装独立客机；主机个人文件与登录资料不会复制。以后启动沿用原系统和磁盘。

便携模式的配置、日志、缓存、下载与客机磁盘都在程序目录内的 `data/`，初始化页显示实际位置，不允许将环境单独迁出该目录。换位置前停止客机并退出，再移动整个程序文件夹。

非便携 Windows 安装器模式可以单独选择环境目录，其配置默认在用户目录的 `.eden`；这不是便携版的数据布局。具体见 [Windows 指南](../windows.md)。

初始化页显示完整路径。系统镜像、镜像下载缓存与持久虚拟磁盘使用所选存储位置。更新、重装与卸载应用保留该目录，重新安装后可继续使用已有 Claude Eden 数据。

Windows 环境使用支持权限管理与稀疏文件的本地 NTFS 磁盘。便携版整目录移动；非便携版独立换盘请按[存储迁移](maintenance.md#迁移环境到另一块磁盘)操作。

## 配置代理并启动

1. 点击“下一步：配置代理”，手动添加 HTTP CONNECT、SOCKS5 或 SSH 节点，保存并验证。详细步骤见[网络与代理](network.md)。
2. 选择一个节点，点击“应用代理”。Claude Eden 使用独立核心，不会自动采用本机 Clash 当前所选节点。
3. 核对匹配的系统镜像、下载量和空间要求，点击“开始安装”。
4. 查看下载、校验、系统安装和工具配置进度。“操作详情”显示错误与检查结果，完整记录可在“日志与诊断”导出；失败后可继续已有安装。
5. 客机可用且网络与隔离检查通过后进入工作台。以后打开 Claude Eden 继续使用原环境。

安装、启动与项目共享不要求修改主机全局 Git 配置，也不要求为裸仓库保护升级 Git。

## 第一次启动需要等待什么

首次安装使用 Debian 13 官方云镜像。基础镜像约 320–325 MiB，工具另行安装。来源、许可和存储要求见[客机系统指南](guest-systems.md#下载量与磁盘空间)。

系统镜像与版本目录通过主机网络下载，遵循主机代理设置；未配置代理时访问官方源。使用 Clash 等软件时，实际出口取决于主机代理或 TUN 的规则。已选择的主机代理连接失败、明确配置的 PAC 解析失败时会报错。客机内的进程和下载使用 Claude Eden 的独立代理，见[系统镜像的下载网络](network.md#系统镜像的下载网络)。

Debian 初始虚拟磁盘容量上限为 24 GiB。实际占用随安装和使用增加，创建前查看所选版本要求。Claude Desktop 按需下载。随后启动复用工具、文件与登录资料。

准备有固定摘要的 Linux 客机工具包时，剩余下载量达到 8 MiB 会尝试最多 4 连接分段下载。小文件、无法取得长度或服务器不支持分段时使用单连接。各连接沿用下载任务的代理设置，收齐并校验整份文件后才用于安装。

Claude Code 和 Claude Desktop 在实际下载安装时查询官方最新版本；已安装的更新版本会保留。环境版本页显示这一下载策略，客机中的版本号以实际安装结果为准。

下载中断时查看错误，修复网络或磁盘空间后点“继续安装”。已有连续进度和分段用于续传；摘要不符或服务器不支持续传时重新下载该文件。没有预先固定摘要的官方最新包可能需要整包重下。便携版保留完整 `data/`，非便携版保留实际配置与系统盘，通过失败步骤继续安装。

下载时显示已接收字节、可取得的总量与采样速度；校验单独显示处理进度。系统恢复和工具安装没有可测总量时显示阶段。继续安装沿用原安装身份和已创建磁盘。

## 完成第一项工作

点项目旁加号打开自己的目录，用“新建 Claude 终端”完成环境内的授权。先让 Claude 读取一个文件或完成小修改，在主机检查结果后再投入正式任务。文件、终端和上传操作见[项目、终端与文件](workbench.md)。
