# ClaudeEden 界面统一规范

## 设计依据

- 已下载并使用 Anthropic 官方 `frontend-design`、`brand-guidelines` 技能，项目目录：`.opencode/skills/`。
- 来源：<https://github.com/anthropics/skills>，固定提交 `e4bb5d960d87126ff3b3a8af1a104b7db67560ba`；保留技能自身许可证，不随运行包分发。
- 官方品牌色用于校准；中文桌面可读性、随包字体、控件高度和既有项目约束优先，不引入 Poppins/Lora 或系统字体依赖。

## 一套基础，不按页面换风格

`internal/uitheme/light.json` 是前端默认主题和控制服务默认外观的共同来源。`ui/src/styles/tokens.css` 在连接页出现前就提供同名 CSS 变量，测试校验两者一致，禁止后端默认外观覆盖成另一套品牌。

| 项目 | 规范 |
| --- | --- |
| 画布／文字 | `#faf9f5`／`#141413` |
| 层级／分隔线 | `#f3f1ea`／`#e8e6dc` |
| 辅助文字／强调 | `#6b6a64`／`#a64b32`（深陶土保证按钮白字对比度） |
| 字体 | 随包 Inter（西文）与 Noto Sans SC（中文）；原生使用由两者合成的 Eden UI |
| 字级 | 正文／控件 14 px；辅助 13 px；分组 16 px；页标题 20 px |
| 高度／圆角 | 常规控件 36 px、紧凑 32 px；控件 6 px、面板／弹窗 8 px |
| 间距 | 4 px 步进；元素 8／12 px、组内 16 px、组间 24／32 px、页面 32／48 px |
| 内容列 | 最大 760 px；设置／初始化按相同基线左对齐；等待／空／错误状态按可见内容居中 |
| 状态 | 错误、成功、警告使用语义变量且有文字，不用裸颜色替代状态说明 |

布局：

```text
连接／等待         初始化／设置                  工作台
  居中状态块       标题 → 说明                   中性侧栏 │ 内容区
  说明             ─ 分组 ─                     32 px 工具栏控件
  操作行           标签 → 控件 → 辅助说明          主动作少量陶土强调
                   ─ 操作区 ─
```

## 覆盖范围及边界

连接及恢复页、初始化三步、账户页、工作台与侧栏、所有设置分组、浏览器管理页、代理管理、账户／密码库、诊断、弹窗、下拉框都使用共享变量和控件，不能单页添加新的品牌色、字号或控件尺寸。

系统所有的文件选择器保持 Windows 的辅助功能与系统交互，不改变宿主主题；原生启动提示保持随窗口／DPI 居中。终端正文继续使用 Noto Sans Mono CJK SC／JetBrains Mono、13 px、xterm 默认色和 OSC 功能，不把界面色板强加给终端内容。客机业务页面本身不冒充应用自有界面换肤。

用户主动保存／导入的外观仍保留；默认安装和重置外观必须统一。不能通过删除已有用户配置或覆盖系统主题让截图看起来一致。

## 验收

1. 校验共享 JSON、前端默认、后端默认及启动前 CSS 变量一致；检查默认主题归一化不丢失元素颜色。
2. 校验字体、常规／紧凑控件、标题、状态及焦点样式。
3. 隔离浏览器连续截图连接、初始化、工作台、设置、浏览器管理、弹窗等真实组件；记录实际覆盖的页面，不把 mock 结果当作真实连接／客机验收。
4. 同一候选在隔离配置中验证冷启动、正常重开、异常退出留存控制记录后的重开；再核对桌面目录实际启动页面。
