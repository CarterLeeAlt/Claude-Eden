# 开始使用 Claude Eden

这份指南从 Windows 10 桌面应用安装开始，带你完成本地 Debian 13 客机的存储与代理配置、启动环境和第一次项目操作。终端、浏览器、编辑器和官方 Claude Desktop 都从同一个工作台进入。

功能按当前开发构建说明；公开安装包包含的入口与验证范围，以对应发行说明为准。详细的日常操作集中在[使用手册](guide/index.md)，本页保留从安装到第一次工作的路径与常用参考。

直接运行便携目录中的 `ClaudeEden.exe`，连接本机工作台并准备 Debian 13；新装不要求注册 ClaudeEden 本地账户或密码，以后沿用本机数据与环境。连接失败时保留错误，修复后点击“重新连接本机”。

## 使用本机环境前的准备

| 需要准备 | 说明 |
|---|---|
| 支持的平台与虚拟化 | Windows 10，当前安装包为 x64；运行本地 Debian 13 需要 Windows 虚拟机监控程序平台，程序按实际电脑检查能力与资源。具体条件见[Debian 13 客机](guide/guest-systems.md)。 |
| 可用的代理 | 自己的 HTTP CONNECT、SOCKS5 或 SSH 节点。Claude Eden 随附 Mihomo 核心，不提供代理服务。 |
| 自己的 Claude 使用资格 | 需要使用 Claude Code 时，在工作环境内完成自己的授权。主机已有登录不会自动导入。 |

首次创建时需要下载 Debian 13 官方镜像和开发工具，请保持网络可用并留出磁盘空间。下载与安装时间由系统和网络速度决定；随后启动复用已有环境。条件见[Debian 13 客机](guide/guest-systems.md)。

## 安装应用

在 [GitHub Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases) 查看实际发布的 Windows 安装包。没有公开安装包时使用 [Windows 构建说明](windows.md#从源码构建)。

| 平台 | 安装方式 |
|---|---|
| Windows 桌面便携版 | 解压后直接运行 `ClaudeEden.exe`，保留 `portable.flag`、`resources/` 和完整 `data/`。无需安装器或 CMD 启动器。实测范围见[当前版本状态](current-status.md)，运行条件见 [Windows 指南](windows.md)。 |

无需先安装开发工具或 Clash。签名、公证和平台验证情况以该安装包的 Release 说明为准。如果系统拒绝打开，先按[安装问题](troubleshooting.md#下载或安装受阻)核对版本与来源。下述代理、环境和项目操作共用。

首次打开直接配置 Debian 13 与代理，不要求用户名或密码。需要本地访问保护时，可在账户设置中主动创建密码账户；下文的密码、记住登录及恢复密钥只适用于主动启用该功能的用户，不是首次使用的前置条件。

便携数据保存在随包 `data/`。主动创建密码账户后请保存恢复密钥；已有账户可在“设置 → 账户”验证密码后补设，忘记密码时在登录页使用密钥重置，详见[账户恢复](guide/settings.md#保存恢复密钥)。ClaudeEden 本地账户不替代 Claude 账号，也不会加密项目文件或整个虚拟磁盘。

### Debian 13 客机

本机客机固定为 Debian 13。Windows 10 主机负责桌面显示和本机文件操作，项目中的程序在 Debian 13 客机执行。

系统镜像来源、空间要求与许可见[客机系统指南](guide/guest-systems.md)。更新 Claude Eden 保留已有系统和磁盘。

### 选择环境存储位置

便携版的配置、日志、缓存、下载、工具数据和客机磁盘统一位于程序目录内的 `data/`。初始化页显示实际位置，不允许把环境单独迁到包外。安装、必要授权与网络检查完成后进入工作台；中断后重新打开仍可继续。非便携安装器模式的存储设置另见 [Windows 指南](windows.md#安装器模式安装并开始工作)。

选择支持私有文件权限和稀疏文件的本地 NTFS 磁盘。

便携版换位置时，先保存工作、停止环境并退出，再移动整个程序目录，保留完整 `data/`。外部共享项目仍从原目录打开，不自动授权另一台电脑的同名路径。非便携模式的独立环境迁移见[维护指南](guide/maintenance.md#迁移环境到另一块磁盘)。

### 首次启动下载什么

客机使用 Debian 13 官方镜像，并准备 Linux 开发工具。初始虚拟磁盘容量上限为 24 GiB，下载量与磁盘空间分别计算，见[下载量与磁盘空间](guide/guest-systems.md#下载量与磁盘空间)。

| 内容 | 来源与用途 |
|---|---|
| Debian 13 基础镜像 | 按处理器架构下载一份，约 320–325 MiB。优先尝试南大、中科大的镜像，再尝试 Debian 官方源，使用项目固定的 SHA-512 校验。 |
| Linux 软件包 | Debian 提供 Chromium、Python、Git、编译工具、远程桌面、字体和系统依赖。安装依赖前先检查 Debian 13 的 APT；低于 3.0.4 时通过官方安全源升级，并保留 Debian 签名与摘要校验。软件包默认优先使用通过连通性探测的南大、中科大镜像，最后回到官方。不可达的镜像本轮跳过；自定义软件源保持原配置。 |
| Node.js、编辑器与工具管理器 | Node.js 24 通过 NodeSource 安装。mise 优先从 npmmirror 下载上游发布的对应架构可执行包。code-server 优先从中科大下载固定版本的 Debian 安装包。两者都按项目固定的 SHA-256 校验，公共镜像不可用时自动回到各自的 GitHub Release。编辑器还会从 SchemaStore 等来源预取 JSON 校验规则供离线使用，缺少某条规则只影响对应文件的校验。 |
| Claude Code | npm 官方注册表提供版本与完整性信息。较大的 Linux 可执行包优先从 npmmirror 下载，使用 npm 官方摘要校验。 |

首次安装和工具升级会自动选择下载来源，无需手动补缓存。中科大的 code-server 镜像只保留最近版本；固定版本缺失时，会直接从 GitHub 下载该版本。下载仍经过当前选择的 Claude Eden 代理。初始虚拟磁盘的容量上限为 24 GiB，下载流量与实际占用取决于架构、软件包版本和已有缓存。以后启动会复用已安装的环境。需要 Claude Desktop 时，在工作台单独安装，届时才访问 Anthropic 的软件源。

需要固定 Debian 官方源时，在客机的 `/etc/workbench/debian-mirror` 中写入 `official`；写入 `auto` 或移除该文件可恢复自动选择。下一次安装或维护时生效，偏好随虚拟磁盘保留，从基础环境克隆出的工作环境也会继承。镜像探测每个地址最多等待 8 秒；安装下载的无响应等待为 15 秒，最多重试一次。APT 升级失败会停止后续依赖安装，修复网络后可重试，无需删除个人数据或虚拟磁盘。

### 受信任的本机登录

注册账户时勾选「记住我」，以后同一系统用户打开 Claude Eden 可自动进入。已有密码账户在登录页验证密码后也可启用，或在「设置 → 账户 → 记住我」中开启或关闭。手动锁定仍需验证，退出账户会撤销此项信任。Claude 服务仍需自己的授权。

受信任模式依赖操作系统的用户登录。离开电脑时请锁定系统。备份时应同时保留账户配置及相应私有信任凭据，保持其原有私有权限，具体位置以当前配置为准。

## 配置并选择代理

进入工作台后点击“配置网络与代理”，之后也可以从“设置 → 网络与代理”进入。

1. 点击“添加节点”，选择 HTTP CONNECT、SOCKS5 或 SSH，填写名称、服务器、端口与认证信息。
2. 点击“保存并验证”。SSH 可选择密码或完整私钥内容，加密私钥还需填写口令。
3. 在节点列表选择一个节点，再点击“应用代理”。可以保存多个节点供手动切换，每次只应用一个节点。

顶部显示当前节点与准确状态：核心运行但环境未启动时显示“待启动环境”，检查通过后显示“已联网”；核心停止或未应用节点时不会放行外网。

添加节点只保存连接信息，应用前的选择仍是草稿。“保存设置”用于 DNS、IP 变化规则等其他设置；代理选择通过“应用代理”生效。编辑当前节点会重建网络连接并复检出口；删除当前节点后保持离线，直到明确应用其他节点。

Claude Eden 使用独立端口和配置，不设置系统代理，不开启主机 TUN，也不改变本机 Clash 的节点选择。节点域名的启动解析属于准备通信；工作环境内的业务 DNS 经过选定节点。

详细操作见[网络与代理](guide/network.md)。

## 启动并等待检查完成

返回工作台，首次创建时确认客机系统与存储位置，再启动环境。无需先选择项目。系统安装和必要授权完成后，后续启动继续使用原环境。

安装、启动和项目共享不检查主机的裸仓库保护设置，也不会改写主机全局 Git 配置。已有的 Git 设置保持原样；需要调整时见[主机 Git 设置](troubleshooting.md#主机-git-设置与裸仓库)。

第一次启动时，工作台会显示当前正在下载或安装的组件。下载 Debian 镜像时可以看到已接收的数据量，服务器提供文件总大小时也会显示百分比。下载 mise、Claude Code 和网页编辑器时，可以看到当前文件已接收的数据量。安装软件包时显示组件名称，点击“操作详情”可查看安装日志。下载中断后，可以点击“继续安装”，Claude Eden 会尝试从已保存的位置续传。环境启动后会连接浏览器并执行网络检查。

环境启动后先关闭业务外网，执行 11 项关键检查，覆盖出口、DNS、系统和浏览器配置、文件共享、宿主管理接口、代理故障关闭、UDP、IPv6 与出口规则。首次构建基础镜像没有项目挂载，需要经指定代理下载工具。

环境就绪、关键检查通过且网络授权有效时，界面显示绿色带对钩的盾牌。检查失败或证据缺失会保持外网关闭，终端、共享文件和环境内的本地网页仍可使用。点击底部网络状态查看具体失败项，修复后重新检查；检查进行中可以取消，也可以停止环境。

首次使用时，默认开启“跟随出口 IP 的时区”，在启动或应用设置时同步工作环境的时区。进入“设置 → 时区与语言”可改为手动选择；已保存的手动选择会保留。语言可以单独开启自动跟随或手动选择。网络与系统设置需要应用后重启环境，界面会提醒保存文件和终端中断。运行中的任务不会因后台发现位置变化而被静默重启。

## 打开项目并开始工作

点击左侧“项目”标题旁的加号，选择已有项目，或点击“添加本机项目…”选择主机上的项目文件夹。新终端和文件编辑器将从这个目录开始工作；没有项目时请先添加一个文件夹。终端使用所选 Linux 客机的系统工具。

点击项目右侧的终端图标，选择“新建 Claude 终端”，Claude Eden 会在该项目中自动运行 `claude`。也可选择普通终端，手动输入命令。“设置 → 通用 → Claude 终端启动命令”可添加参数，例如 `claude --continue`；保存后只影响新建的 Claude 终端，退出 Claude 后仍可继续使用 shell。

打开“设置 → Claude 账号”。如果你已在工作台普通终端用 Claude Code 登录订阅，环境就绪后，页面会显示默认终端检测到的邮箱。点击“加入调度”即可复用这份登录。主机上的应用和系统终端有各自的登录，面板只检查工作环境里的 Claude Code。

要添加另一个订阅，点击“登录新账号”，在临时浏览器窗口完成官方授权。Claude Eden 为这次登录分配独立目录，成功后按邮箱登记并参与调度，也可以再改备注。取消登录不会增加一个可调度账号。以后点击项目右侧的终端图标新建 Claude 终端，标签会显示它分配到的账号。

如果普通终端原先登录 A，后来登录 B，Claude Eden 会停止把默认目录分配给 A。B 需要单独点击“加入调度”。要让 A 和 B 长期同时在线，可以保留一份默认登录，再用“登录新账号”为另一个账号建立独立登录。

关闭某个账号的“参与自动分配”只影响之后新建的终端，正在使用该账号的会话可以继续。打开账号面板时，Claude Eden 会向客机里的官方 Claude Code 查询五小时和七天额度。点击卡片的“检查状态”可立即重查该账号，无需先发一条模型消息。某个窗口没有返回读数时，面板会说明结果，并保留该窗口上一次的百分比和读取时间。[账号调度与额度说明](guide/accounts.md)

新会话可均衡分配或按列表顺序选择账号。已有会话只有在明确授权、同一接续分组且原任务可安全停止时，才能切换账号恢复历史；也可预先允许额度确认耗尽后的自动接续。技能、指令与同项目记忆的共享范围，以及原生客机验证条件，见[多账号与额度](guide/accounts.md)。Claude Code 标签中的 Agent 编号表示当前绑定账号。

可以先让 Claude 读取项目并解释一个文件，确认模型请求正常，再让它在测试文件中完成一个小修改。通过“浏览文件”查看内容，并在主机上确认同一文件的变化。首次使用前请备份重要项目。

文件修改会直接作用于共享目录。项目内的 `.git` 可读写，可以让 Claude 修改代码，并在 Claude Eden 中审查、暂存和提交。

点击左侧“浏览器”可返回正在使用的浏览页面；通过顶部加号新建网页。地址栏中的 `localhost` 指向当前 Workbench 客机，可用于预览在工作台终端中启动的开发服务。

## 日常使用

### Claude 官网与桌面应用

浏览器下方的 `claude.ai` 入口直接在 Workbench 浏览器中打开官网。`Claude Desktop` 入口提供官方桌面应用：首次点击“下载并安装”，Claude Eden 从 Anthropic 官方源完成安装，随后打开应用；Chat 和 Code 在同一个应用内切换。安装前先启动环境并确保所选代理可用，无需等待业务网络放行；应用内联网仍需通过网络检查。安装失败时可查看进度并重试。

Linux 环境新配置默认关闭“设置 → 通用 → 优先流畅”，浏览器和 Claude Desktop 使用 2 倍像素渲染。开启并保存后，下次启动环境改为 1.5 倍，控件大小保持不变；关闭后下次启动恢复 2 倍。

Desktop 的画面会随 Claude Eden 窗口和侧栏自动调整。右上角“显示大小”默认 100%；选择较小的值可以显示更多内容，较大的值可以放大文字和控件，无需重启应用。调整结果会在本机保留。若提示画面尺寸未能同步，点击“重试调整”。

应用只在使用时下载和启动。切换到浏览器或终端时保持运行；点击应用上方的“关闭应用”释放其运行资源，登录数据仍保留在客机中。应用关闭后可“更新 / 修复安装”。Claude 账号的首次登录在工作环境内完成，不导入主机账号。Linux 客机的密钥环由工作台管理，修改 Claude Eden 密码会保留应用登录数据。需要额外虚拟机的 Cowork 功能暂未适配。

应用页或 Claude Eden 主机窗口不可见时，工作台暂停对应用状态的定时检查；返回时立即重新读取。应用内任务继续运行，画质设置保持原有选择。

Linux 客机中由 Claude Eden 管理的 Desktop 在最后一个查看者断开后自动隐藏窗口，减少后台绘图；再次打开画面时恢复。应用进程与正在执行的任务继续运行。

### 锁定与退出账户

左下角头像菜单中的锁定操作隐藏工作台并要求重新输入密码，正在运行的 Claude、终端和环境任务继续运行。“退出账户”会先提醒保存文件，再停止环境并锁定凭据。仅退出应用时后台任务继续运行。“设置 → 账户 → 记住我”可开启本机自动登录，下次用当前系统用户打开时直接进入；手动锁定后仍需密码，重新打开也不会跳过验证。退出账户会撤销本机快捷登录授权。

### 保存网站账号密码

在 Workbench 浏览器中提交邮箱等网站的登录表单后，浏览器工具区会提示保存账号密码。先确认网站登录成功，再点击“保存密码”；密码变化时可选择“更新密码”。“此网站不再提示”只关闭该网站的保存提示。

再次打开同一网站时，展开浏览器工具区的“密码”，选择账号填入登录框，再自行提交。当前支持 HTTPS 顶层页面的常见表单；嵌入框架、验证码和 Passkey 不自动处理。旧环境如果提示密码功能不可用，先到“设置 → 环境与恢复”更新环境组件。

在“设置 → 密码保险箱”中可以搜索、添加、编辑、删除记录，或恢复某网站的保存提示。查看、复制密码需要再次输入 Claude Eden 账户密码。保险箱随工作台一起解锁和锁定；已启用记住登录时，也会随之解锁。密码只保存在本机，备份时需同时保留配置目录中的账户文件与密码库，具体边界见[密码保险箱设置](guide/settings.md)。

### 项目、标签与文件

左侧“项目”列出明确打开的文件夹，列表由 Claude Eden 保存，重新打开应用后仍可看到。每个项目右侧有两个图标。点击打开图标（↗）可在编辑器中编辑该目录的文件。点击终端图标（`>_`）可选择终端类型，在该目录新建终端。已有终端始终留在创建它的目录下。所有项目共用一个持久环境，所选客机系统、工具、账户和文件系统也相互共享。已打开的目录在环境启动时恢复连接。

浏览器独立于项目，网页和文件编辑器使用顶部标签页；切换项目不会关闭或迁移网页。将鼠标移入终端行，或用键盘聚焦该行，即可在右侧置顶、重命名或删除终端。浏览器标签可通过右键或 Shift+F10 打开操作菜单。拖动可调整同一列表内的顺序，刷新后保留。Ctrl+1–9 切换当前浏览器的页面或当前目录的终端。

点击浏览器工作区右上角的 ×，退出浏览器视图并返回打开前的首页、终端或 Claude Desktop；原来的终端已结束时返回首页。横排与竖排标签均提供此按钮，双网页分屏共用一个关闭按钮。网页标签、登录和后台无痕会话继续保留，再次点击侧栏“浏览器”可以继续使用；结束无痕会话需关闭全部无痕标签或停止环境。

标签较多时会自动缩短，当前页面的标签保留更多标题空间。拖动时其他标签即时让位，松手保存顺序，Esc 取消；置顶标签在置顶分组内排序。右侧向下箭头可以搜索已打开的页面。

点击地址栏右侧的星标或按 Ctrl+D 收藏当前网页，可修改名称并选择或新建收藏夹。点击旁边的收藏夹按钮或按 Ctrl+Shift+O，可搜索、打开和编辑收藏；编辑时可移动到其他收藏夹。删除收藏夹会把其中的网页移至“未分类”。收藏保存在本机当前 Claude Eden 配置中，所有项目共用，重启后保留。

### 浏览器设置与扩展

在浏览器右上角“…”菜单点击“设置”，即可打开独立的设置标签；再次点击会回到同一标签。“新标签页”中可保存默认网址，“外观”中选择横排或竖排标签，“隐私与网站数据”中管理 Cookie 和网站权限。这些浏览器专属设置由浏览器自身管理。

进入“扩展”，可以添加 Manifest V3 的 ZIP 扩展。选择文件后先检查名称、版本和权限，再点击“安装扩展”。已安装列表支持启用、停用、移除和打开扩展选项；也可进入 Chromium 原生扩展管理或扩展商店。安装和启停状态随当前工作环境保存，重启后继续使用。

点击“从本机导入”，选择 Edge、Chrome、Brave 或 Chromium 的用户配置，核对清单后导入所选扩展。原启停状态能读取时按原状态导入，无法读取时显示说明并保持停用。不兼容或已导入的扩展会单独标明；失败项目给出原因，不影响其余项目的结果。完成后点击“完成并关闭”，回到已安装列表。

导入一次后，两边独立管理。本机浏览器的账户、Cookie、扩展登录数据与原生伴随程序不会包含在程序包中，相关扩展可能需要重新登录或配置。部分扩展依赖浏览器专属能力或授权，兼容范围以扩展在 Workbench 浏览器内的实际运行结果为准。详细机制见[浏览器设置与扩展](guide/browser.md)。

### 无痕浏览与 Cookie

点击地址栏右侧的“浏览器菜单”，选择“新建无痕标签”，或按 Ctrl+Shift+N。无痕标签在标题和地址栏中显示“无痕”。在无痕页点击标签栏加号或按新建网页快捷键，会继续创建无痕标签；从菜单选择“新建普通标签”可返回普通浏览。

普通网页与无痕网页的 Cookie、登录状态和网站存储相互隔离，同一批无痕标签之间共享临时会话。关闭最后一个无痕标签后清理该会话，重启环境不会恢复无痕网页。无痕页不会提示保存密码，标签重命名和排列也不写入本地持久存储。下载文件及主动保存的收藏继续保留。仅关闭或隐藏 Claude Eden 窗口会保留后台浏览器；结束无痕会话应关闭所有无痕标签或停止环境。无痕浏览继续使用工作环境的网络出口，网站和代理服务仍可识别相应请求。无痕网页可以与终端分屏，双网页分屏目前仅支持普通标签。

在浏览器菜单选择“管理 Cookie”，即可查看当前网站的 Cookie，或切换到“所有网站”。列表支持按网站或名称搜索、查看值、删除单条，以及清空当前网站或当前会话所有网站的 Cookie。每次操作仅影响当前标签所属的普通或无痕会话；清空范围不受搜索条件限制，需要再次确认，完成后网站可能要求重新登录。清空普通会话的所有 Cookie 也会清除文件编辑器的认证，可通过编辑器菜单的“恢复编辑器”重新打开。Cookie 清理保留网站的其他存储，例如 localStorage。

### 浏览器上传与下载

在网页中点击上传后，工作台显示“上传本机文件”。点击“选择本机文件”，即可用系统文件窗口选择图片、视频或文档，传递状态会显示在面板中。只传递所选文件，不增加文件夹共享。网页允许多选时最多选择 100 个文件，每个文件不超过 2 GB；目标网站自身的格式与大小限制仍然有效。可以取消上传，刷新或关闭原网页后需要重新选择。Claude Desktop 的文件上传也使用此本机选择入口；如果仍显示客机文件窗口，先保存并关闭 Claude Desktop，再重新打开。在 Claude Desktop 的 Code 页选择工作文件夹时，Claude Eden 会显示“选择工作项目”，列表与左侧项目列表保持一致。选中已有项目后点击“使用此项目”；新目录通过“添加本机项目…”打开系统窗口，确认后加入项目列表并交给 Claude。Claude 选择项目不会切换工作台当前项目或已有终端。该目录中的改动会同步到本机。

网页下载仍在客机内完成。本机先收到下载暂存目录中的完整文件，同名文件自动换名。工作台连接期间观察到下载完成后，会弹出系统“另存为”窗口；取消时保留默认位置的文件。共享目录暂时不可写而客机文件已完整下载时，也可以从下载列表直接另存为。

左侧“下载”入口和地址栏旁的下载按钮都可查看进度、文件名和保存位置，并提供“打开文件”“在文件夹中显示”“另存为”。已记录的本机文件在停止环境后仍能查看；再次打开 Claude Eden 也保留保存位置。便携下载暂存位于随包 `data/`，以界面显示的实际路径为准，无需添加项目即可下载。用户主动“另存为”选择的外部文件仍保存在所选位置。

Desktop 的主机文件操作只接受已授权项目或已保存下载记录中的文件，生成文档须先完成保存。Linux 客机提供对应文件入口，完整官方应用的上传、保存、打开与定位验收范围以发行说明为准。需要其他目录时，先通过“添加本机项目…”明确授权；更新后关闭再打开 Desktop。当前条件与恢复方法见[Claude Desktop](guide/desktop.md#选择项目与传文件)。

### 关闭、退出与再次打开

| 操作 | 会发生什么 |
|---|---|
| 关闭窗口 | 环境和后台终端保留运行。 |
| 退出时选择保留环境 | 后台任务继续运行，下次打开 App 重新连接。 |
| 停止环境，或停止环境并退出 | 终端进程结束；项目文件、虚拟磁盘与登录状态保留。 |
| 刷新工作台 | 可重新连接控制服务中仍存活的终端。 |
| 重启控制服务或虚拟机 | 旧终端会话不能恢复，需要新建终端。 |

停止前先保存编辑器中的修改。再次打开 Claude Eden 会使用同一环境，无需重新导入项目或重新创建虚拟磁盘。

切到终端、设置页，或隐藏、最小化窗口时，Claude Eden 暂停浏览器画面的显示连接，保留浏览器页面、下载和后台任务。画面重新可见时自动连接；这项节省显示资源的行为不等于暂停浏览器或停止环境。

### 按键与剪贴板

Windows 默认采用 Ctrl 按键习惯，网页和编辑器使用 `Ctrl+F`、`Ctrl+Z` 等快捷键。终端复制粘贴使用 `Ctrl+Shift+C/V`，保留 `Ctrl+C` 中断命令。

在 Claude Desktop、Claude Code 和普通终端的多行输入中，按 `Shift+Enter` 在当前输入内换行，按 `Enter` 提交消息或执行命令。网页和 Desktop 的目标输入框须支持多行；终端程序须支持多行粘贴或识别 Shift+Enter。Bash、zsh 启用多行粘贴时，换行不会执行已写好的命令；自行关闭此模式或使用其他终端程序时，行为取决于程序的按键支持。中文输入法仍在选择候选词时，回车先由输入法处理。

复制粘贴支持纯文本、中文、多行和 emoji。先点击目标输入框，再使用快捷键或工具栏按钮；普通浏览器限制剪贴板权限时，可用“文本传递”面板。Claude Eden 仅在主动复制或粘贴时访问本机剪贴板，不持续轮询。

Workbench 浏览器中的网页复制按钮也可同步纯文本到本机。点击后保持当前网页和 Claude Eden 窗口处于前台，出现“已复制到本机”即可在其他应用粘贴。如果网页采用不受支持的旧式复制方式，或复制期间切换了标签、输入位置或窗口，可重新复制，或使用复制快捷键和“文本传递”面板。

本机截图可以粘贴到工作台。视频、文档和图片文件可以直接拖入工作内容区，也可以先在本机文件管理器中复制，再到工作台粘贴。文件保留原始名称与内容，包括 GIF 动画；单文件最多 2 GB，一次最多 100 个。网页拖入会交给落点，文件粘贴会交给当前输入位置，目标网页须支持附件拖入；Claude Desktop 须先点击支持附件的输入位置。终端把文件保存到客机附件目录并插入带引号的路径，供 Claude Code 等工具读取，不自动执行命令。

截图粘贴上限为 20 MB、4000 万像素。Claude Eden 通过本机与客机的控制通道传递附件，不借助外部存储服务；目标网页或应用可以按自身行为上传。终端附件保留到用户自行删除，Desktop 的上传副本保留到图形会话重建。切换目标或断开连接后，尚未发送的输入会取消。已有环境的组件需要更新时，按应用提示处理。

### 外观与浏览器首页

“设置 → 外观”提供亮色界面配色。基础配色可调整强调色、背景和文字，展开“自定义”后，还可分别调整侧栏、工具栏、标题、辅助文字、边框、输入框、按钮、链接、焦点、悬停、选中及状态提示颜色。

预设下拉框按“经典、编辑器、阅读、无障碍”分组，共有 10 套亮色配色：Codex、Solarized、VS Code Modern / Classic、GitHub、Nord、纸白、暖纸、色觉友好与高对比。选择预设会应用界面配色，替换当前元素颜色覆盖；已保存的自定义主题可随时恢复。

“无障碍 → 色觉友好 · 蓝橙”用蓝色与橙色区分成功和错误，减少红绿依赖；“高对比”使用白底黑字，并加强边框与焦点。两类预设都采用不透明侧栏，使对比保持稳定。卡片中带图标和文字的成功、警告、错误预览，可帮助比较状态色。不同色觉差异的适用配色会有差别，可继续自定义并另存主题。

颜色支持取色器和六位 HEX 输入。HEX 输入按 Enter 或离开输入框后生效；单独设置的颜色旁可恢复自动配色。字号、对比度、指针和动态效果也在此调整。修改即时生效并自动保存，失败时保留当前输入，可点击“重试保存”。

界面内置 Noto Sans SC 中文字体和 Inter 西文字体，基准字号为 14 px；终端、日志和代码预览内置 Noto Sans Mono CJK SC 中文字体和 JetBrains Mono 西文字体，基准字号为 13 px。所需字体随应用加载，字号可独立调整。Windows 启动器、托盘菜单、自有提示框和安装器使用同一套界面字形；系统标题栏和系统文件选择窗口使用系统字体。

终端配色由终端程序配置，初始使用 xterm 默认配色，并接受程序发出的 OSC 颜色控制指令。Claude Code 的 `/theme` 调整 Claude 内容配色；`auto` 根据终端背景选择，`/theme` 本身不改变终端底色。客机网页与编辑器使用各自的外观设置。

在“我的主题”中输入名称，点击“另存为主题”，即可将界面配色和侧栏透明度保存为一个主题。下拉框用于切换主题；修改后可“更新此主题”，也可另存，或点击“恢复已保存配色”放弃此次配色调整。删除主题会保留当前配色。最多保存 50 个自定义主题。

“导出主题”将当前界面配色保存为 `.eden-theme.json` 文件；“导入主题”校验文件后添加并应用，同名文件会另存，不覆盖已有主题。桌面版通过系统文件窗口读写，浏览器版使用文件选择与下载。主题文件仅包含配色和侧栏透明度，字号及交互偏好单独保存。文件须为不超过 256 KB、格式标识为 `eden-theme`、版本为 `2` 的 Claude Eden JSON 主题，格式版本不支持或内容无效时保留当前设置。

“从本机 Codex 同步”可复制 Codex 的亮色配色、字号和交互偏好，导入后独立保存，并保留 Claude Eden 中已保存的自定义主题。

浏览器“…”菜单的“设置 → 新标签页”控制新网页的默认入口，初始为 Bing；保存后下次打开网页生效，无需重启环境。

### 计算资源上限

“设置 → 环境与恢复 → 计算资源”默认自动设置上限：内存取主机份额与 8 GiB 的较小值，CPU 按主机份额分配。关闭“自动分配资源上限”后，可分别指定内存 GiB 和 CPU 逻辑核心数，手动内存仍可使用完整主机份额，可填范围显示在输入框下方。点击“保存资源配置”后，下次启动环境时生效；运行中可点击“重启并应用已保存配置”，请先保存工作，重启会结束正在运行的命令。内存仍会在指定上限内按需增长和回收。

### 时区、语言和出口变化

新用户默认开启时区和语言跟随出口 IP。自动时区经代理查询出口位置，采用返回的 IANA 时区；保存时和停止后的下一次启动会同步。位置服务不可用时显示错误，不使用主机位置代替。IP 定位依赖外部数据库，不能保证节点的物理位置。

语言支持简体中文、繁体中文、英语、日语、韩语、德语、法语，可独立跟随出口地区，也可手动选择。自动模式使用支持范围内的地区默认值，多语言地区可自行调整；没有对应建议的地区保留现有语言。工作台界面使用中文，客机系统与网页首选语言可分别设置。

“设置 → IP 变化规则”支持静态 IP，以及动态 IP 的同一城市、同一州／省、同一国家／地区、不限地区。城市规则同时检查国家、州／省和城市。规则与选定节点的关联、首次绑定及切换行为见[时区、语言与出口规则](guide/network.md#时区语言与出口规则)。同一节点已有的基准只在用户明确修改时改变，重检不会自动接受新出口。

### 查看检查、暂停与恢复网络

点击底部网络状态可查看证据、重检或暂停外网。暂停会切断已有外部连接，终端和文件仍可离线使用。第三方 IP 信誉仅作提示，不单独决定联网；社区检查网站需要用户主动打开。

人工暂停会保存，关闭并重开后台、编辑当前节点后仍保持暂停。暂停记录缺失或损坏时，Claude Eden 默认保持外网关闭；确认后可通过启动环境、重新检测或手动应用网络配置恢复。若提示无法保存状态，当前外网仍会关闭，请解决配置写入问题后重试。

后台约每 30 秒核对出口与环境配置，发现不符合规则时暂停外网。网络放行每次最多 90 秒，控制服务失联后到期关闭；完整报告最多有效 24 小时，过期需要重检。HTTP/SOCKS5 代理可能按连接分配不同出口，抽样检查不能证明每条连接使用相同 IP；固定出口仍需代理服务自身保证。

## 网络与数据边界

Claude Eden 的本机环境使用独立的 Debian 13 虚拟机。浏览器与编辑器在客机内执行，本机工作台呈现画面和终端；Chromium 以普通用户运行并保留自身沙箱。

- **代理故障时客机绝不直连是 Claude Eden 必须满足的硬规则。** 对外 TCP 在主机侧虚拟网卡出口统一交给指定代理，DNS 经同一代理转为 DoH。代理核心退出、上游不可达、认证或解析失败、配置失效时，只能请求失败或关闭公网，禁止自动回退主机直连、系统代理或主机 DNS；首次客机安装、更新与恢复也遵守此规则。适用范围与验收要求见[客机网络硬规则](guide/network.md#客机网络硬规则)。
- 客机公网 IPv6、普通 UDP、ICMP，以及到主机和局域网的直连受限；当前公网出站支持 IPv4 TCP。SSH 管理、共享文件和本地显示使用明确的内部通道。主动启用 [Tailscale 私网](guide/tailscale.md)后，可按设备和 SSH 权限双向连接，外层通信仍受代理与暂停控制。
- 代理凭据保存在主机私有配置，不传入客机。终端 SSH 禁用本机转义、本机命令、代理转发与交互密码，且不继承主机环境变量。
- 工作台只监听本机 loopback，App 自动换取会话；接口校验 Host、Origin 与会话，外部网页不能直接调用管理操作。
- 明确打开的项目目录及下载暂存目录会共享到同一环境，彼此可以访问。修改、删除共享文件会影响主机，请保留备份。不要把 Claude Eden 私有配置目录或正在运行的控制程序作为共享项目。

网络约束在本机虚拟机外，客机内的权限不能直接关闭外部控制。虚拟机或浏览器漏洞、主机管理员修改配置，以及用户在主机执行共享项目中的脚本，超出这层边界能阻止的范围。Claude Eden 不提供账号封禁预测或避免限制的承诺。镜像化分享和系统时钟伪造尚未提供。

### 播放环境声音

在 Workbench 浏览器播放视频或音频时，声音会从本机当前的扬声器或耳机输出。点击底部的扬声器按钮展开音量滑块，调整整个工作环境的音量；展开时再次点击扬声器可以静音或取消静音。鼠标移出控件后滑块自动收起。Claude Desktop 和终端程序共用此控制。若播放受到限制，点击页面后继续播放。

切换标签或项目不会停止声音。静音、停止环境、锁定 Claude Eden 账户或退出应用会断开播放；取消静音后播放当前内容，不补播中断期间的声音。已有环境缺少所需组件时应先更新。此功能提供声音输出，不提供本机麦克风输入。

## 升级与卸载

便携候选尚未完成自动更新验收，不要用安装器覆盖便携目录。替换程序前保存工作、停止环境并退出，备份并保留完整 `data/`。下文自动安装与系统卸载仅适用于安装器模式，参阅 [Windows 更新与卸载](windows.md#更新与卸载)。客机组件与工具在工作台设置中更新。

便携版的账户密钥、收藏、设置、浏览器历史、网站登录状态和持久环境均依赖完整 `data/`，不能只拷贝 `account.json` 或单独的虚拟盘。非便携模式的默认配置为 `~/.eden/`，环境存储以实际配置为准。终端窗口的临时输出和正在运行的进程不属于磁盘备份。

已创建过账户却再次出现创建页面时，先按[账户与数据目录检查](troubleshooting.md#已有账户却再次显示创建账户)核对目录，不要创建新账户或删除旧配置。

应用会在启动后自动检查更新，运行期间每六小时重查；普通检查失败后每五分钟重试，更新源要求等待时按其指定时间重试，隐藏窗口期间暂停检查。没有新版时不显示更新入口。有新版时，左下角显示金色圆形下载按钮；请先保存文件并结束运行中的任务，再点击一次。按钮会显示环形下载进度和百分比，下载校验完成后自动停止环境、安装并重启，不再弹出确认框。应用更新会结束工作台终端，保留项目、配置、虚拟磁盘和登录状态。失败时显示原因，点击原按钮可重试；限流等待期间按钮禁用，悬浮可查看最早重试时间。

检查和下载使用已经应用并运行的所选代理，失败不会改用主机直连。自动安装要求当前应用和安装包通过 Authenticode 校验且具有相同发布者公钥；未签名开发构建不能自动安装。更新器使用当前仓库公开的 GitHub Releases 接口，不读取浏览器会话。若提示更新源不可访问，先确认所选代理可用，再检查对应 Release 是否公开且附件完整。实际安装、重启和恢复的验收范围以该版本说明为准。

手动运行新版安装程序前，保存文件并选择“停止环境并退出”。新应用会核对后台版本；若出现“更新待完成”，可先打开现有环境保存文件，再选择“保存后停止环境并完成更新”。

“设置 → 环境与恢复”分别提供环境组件与工具更新，并显示实际版本。组件更新会重启浏览器和编辑器，保留 VM、磁盘和工作台独立终端；编辑器内的集成终端可能结束，操作前需要保存内容。依赖安装和工具更新使用所选代理，无需业务网络已经放行；工具更新采用当前 App 指定的最低版本，人工暂停外网不会被更新操作解除。替换 App 不等于已经升级全部 Linux 工具。

卸载应用前应先停止环境并退出，再在 Windows“设置 → 应用”中卸载 Claude Eden。卸载不会自动删除共享项目、下载暂存、代理配置或虚拟磁盘。需要清理数据时先备份私有配置和实际环境存储目录，自行打开的项目仍在原目录。删除虚拟磁盘会丢失只存在于客机中的文件和登录状态。
