# Linux 云端与客机

Claude Eden 保留 Linux 云端部署、后端服务，以及 Windows 桌面宿主中的 Linux 客机。日常桌面入口为 Windows 应用，Linux 服务器按云端部署流程运行。

## Linux 云端

在 Windows 工作台侧栏添加 SSH 主机，保存服务器地址、SSH 用户和密钥。首次连接时核对主机指纹；目标已部署时连接工作台，首次部署时按界面确认部署范围。服务器要求、容器网络与持久目录见[云端使用指南](guide/cloud.md)和[部署说明](../deploy/cloud/README.md)。

云端环境使用服务器容器，不要求 KVM。项目、工具、账户状态和执行任务保存在服务器，出口也由服务器上的代理与隔离网络控制。SSH 能连通不代表客机业务网络已放行；应在工作台核对节点和网络检查结果。

共享项目的修改会直接作用于对应原文件。备份应覆盖部署配置、持久数据目录及项目；更新和卸载按部署说明执行，先保存并停止需要结束的任务。

## Windows 上的 Linux 客机

Windows 10 22H2 / 11 x64 可选择 Debian 或 Ubuntu 22.04 客机，使用 QEMU 与 Windows 虚拟机监控程序平台。首次安装下载官方镜像与开发工具，之后使用持久虚拟磁盘；具体版本、校验与空间要求见[客机系统指南](guide/guest-systems.md)。

Linux 客机普通账户为 `developer`，客机辅助工具采用 `Workbench` / `workbench` 标识。宿主程序和配置使用 `Claude Eden` / `eden`；两者职责和目录不同。

## 排查与反馈

- SSH 连接失败：先核对地址、端口、用户、主机指纹与密钥权限。
- 部署失败：查看对应步骤日志、服务器发行版、容器运行时、磁盘与网络条件。
- 环境不能联网：在工作台确认有效代理和网络检查；服务器自身联网不代表工作环境已放行。
- 本机 Linux 客机不能启动：按 [Windows 指南](windows.md)核对虚拟化及 WHPX 条件。

反馈时提供 Claude Eden 版本、Windows 或 Linux 服务器版本、CPU 架构、失败步骤和错误原文，避免附带代理密码、订阅链接、账户文件和带会话信息的地址。
