# 当前版本与验收状态

本页只说明当前 `0.1.8-rc` 候选，不保留过往交接流水账。功能、构建和测试结论必须区分；局部通过不等于正式交付通过。

## 当前产品

- Windows 10 x64 宿主，运行实际的本地 Debian 13 客机；虚拟化、资源和路径按当前电脑检测。
- 便携入口为 `ClaudeEden.exe`，通过同目录 `portable.flag` 启用。配置、日志、缓存、下载和客机磁盘留在随包 `data/`；首次使用不要求 ClaudeEden 本地账户或密码。
- 便携内部路径基于当前位置解析，包内项目和环境位置使用相对引用。换位置前停止客机并退出，移动整个目录；外部项目不会自动改授另一台电脑上的同名目录。
- Wails 3、React／严格 TypeScript、Go 独立控制服务。统一亮色界面，使用随包 Inter／Noto Sans SC；终端使用随包等宽字体与 DOM 渲染。
- Mihomo 只应用一个明确选定的 HTTP CONNECT、SOCKS5 或 SSH 节点；检查未通过或代理故障时，客机公网必须失败或关闭，不回退直连。

运行要求见 [Windows 支持](windows.md)，使用入口见 [文档导航](README.md)，设计规范见 [界面设计系统](ui-design-system.md)。
