# Claude Eden 文档入口

首次使用 Claude Eden，从 Windows 安装与代理配置开始；已有环境遇到问题时，直接查故障恢复。实际发布的安装包与验收范围见 [GitHub Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases)，产品介绍见[项目主页](https://github.com/CarterLeeAlt/Claude-Eden)。
