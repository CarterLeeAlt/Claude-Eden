# 当前 TODO

这里记录当前版本明确延期、尚未完成的工作。列入 TODO 不等于通过验收，也不放宽“代理故障时客机不得直连”的要求。已完成范围见[当前版本状态](current-status.md)。

## P0：补齐代理故障关闭的两端网络证据

- [ ] 准备有权使用且可查看接收日志的公网测试服务，以及可查看权威查询日志的测试域名／DNS 服务。这些是验收设施，不是用户运行软件的依赖，也不要求第二台本地 Windows 电脑。
- [ ] 每次 TCP 请求和 DNS 查询使用唯一编号，关联客机发起记录、宿主进程与连接记录、目标服务访问日志及 DNS 查询日志，区分代理连接、宿主准备下载、代理域名启动解析和内部管理通道。
- [ ] 覆盖 HTTP CONNECT、SOCKS5、SSH 及所支持认证方式的正常与真实故障路径，核对没有绕过所选代理的 TCP 或 DNS。宿主侧可使用抓包或可归因连接观测，不将定时采样“未看见连接”单独当作充分结论。

**现有结果：**当前候选的 26 项上游故障与恢复测试通过；749 次宿主连接采样未见产品进程连接公网目标。但独立接收端与 DNS 服务记录缺失，完整硬规则验收尚未完成。

## P0：补齐当前候选的联网生命周期矩阵

以下场景均须检查新请求及已建立的长连接，并与上面的两端网络记录对应：

- [ ] 终止代理核心；代理配置缺失、损坏或失效。
- [ ] 客机正在联网时强制结束控制服务，以及联网许可到期；确认许可失效后关闭已有外连，不把剩余期限当作直连宽限期。
- [ ] 手动暂停、节点切换、启动、取消、重试及恢复；确认失败时不放行、恢复必须通过现有检查，人工暂停不被自动解除。
- [ ] 宿主网络切换；同时核对公网 UDP、IPv6、ICMP、宿主与局域网访问限制未被削弱。涉及宿主网络状态改变时先单独确认具体操作与恢复范围。

**现有结果：**当前候选的桌面强制退出／旧记录重开，以及正常客机启动、停止和控制服务退出通过。它们不替代上述带实际流量的故障关闭检查；旧候选的生命周期结果也不算当前候选全量通过。
