## Anthropic ကို စိတ်ကုန်နေပြီ

Claude နှင့် စကားပြောပြီး ပူးပေါင်းလိုသော်လည်း VPS၊ browser profile နှင့် ပတ်ဝန်းကျင်စစ်ဆေးမှုများ ပြင်ဆင်ရခြင်းကို ငြီးငွေ့ကာ အကောင့်ပိတ်ခြင်းနှင့် ငွေကြေးဆုံးရှုံးခြင်းကို စိုးရိမ်ရသည်။ **Claude Eden** ကို မိတ်ဆက်ပါသည် — **ကိုယ်ပိုင် proxy၊ သီးခြားပတ်ဝန်းကျင်၊ အချိန်ဇုန်၊ ဘာသာစကားနှင့် စစ်ဆေးမှုများကို တစ်နေရာတည်းတွင် စီမံနိုင်သော desktop အလုပ်ခွင်ဖြစ်သည်။**

Claude Eden သည် terminal၊ browser၊ editor နှင့် တရားဝင် Claude Desktop ကို Windows desktop တွင် စုစည်းပေးသည်။ Local Windows သို့မဟုတ် Linux guest ကို အသုံးပြုနိုင်ပြီး ကိုယ်ပိုင် Linux cloud server ကို SSH ဖြင့် ချိတ်ဆက်နိုင်သည်။ ရွေးထားသော project များကိုသာ မျှဝေပြီး ကွန်ရက်ကို သီးခြားစီမံကာ ဖုန်းမှ အလုပ်ဆက်လုပ်နိုင်သည်။ Host လိုအပ်ချက်နှင့် guest စွမ်းရည်များကို စနစ်လမ်းညွှန်တွင် ကြည့်ပါ။ အဓိကလုပ်ဆောင်ချက်များမှာ—

- ကွန်ရက်ဆက်တင်များသည် host နှင့် သီးခြားဖြစ်ပြီး Claude Eden က အတွင်းကွန်ရက်အသွားအလာအားလုံးကို ကိုယ်ပိုင် proxy မှတစ်ဆင့် ပို့ပေးသည်။
- အချိန်ဇုန်နှင့် ဘာသာစကားအပါအဝင် ကွန်ရက်ပရောက်စီ၏ IP တည်နေရာသို့ အလိုအလျောက်ထပ်တူပြုခြင်းဖြင့် ဘရောက်ဆာလက်ဗွေဆက်တင်များကို ခွဲထုတ်ထားသည်။
- Claude အလုပ်အသွားအလာတစ်လျှောက် ပေါင်းစည်းခြင်း- ဘရောက်ဆာ အကောင့်ဝင်ခြင်း၊ အကောင့်ခွင့်ပြုချက်နှင့် Claude Code လုပ်ငန်းစဉ်
- အရေးကြီးသောစစ်ဆေးမှုများ ပျက်ကွက်ခြင်း သို့မဟုတ် အထောက်အထား မပြည့်စုံသောအခါတွင် ထည့်သွင်းထားသော ကွန်ရက်နှင့် သီးခြားစစ်ဆေးခြင်းများသည် အင်တာနက် အသုံးပြုခွင့်ကို ခေတ္တရပ်ထားသည်။ အသိုင်းအဝိုင်းနှင့် ပြင်ပအဖွဲ့အစည်း စစ်ဆေးမှုများသည် ထပ်လောင်းကိုးကားသည့် အချက်အလက်ကို ပေးပါသည်။

## Claude Eden နဲ့ သင်ဘာလုပ်နိုင်လဲ။

- **ဝင်းဒိုးတစ်ခုတည်းတွင် အလုပ်လုပ်ပါ။** Terminal တွင် Claude Code ကိုဖွင့်ပါ၊ editor တွင် ပြောင်းလဲမှုများကို ကြည့်ပါ၊ ဝန်ဆောင်မှုအစမ်းကြည့်ရန်နှင့် အကောင့်ဝင်ရန် Workbench browser ကိုသုံးပါ။
- **ရင်းနှီးပြီးသားစနစ်တွင် ဖန်တီးပါ။** Windows သို့မဟုတ် Linux guest ကို ရွေးပါ။ သင့်လျော်သော Windows host သည် စနစ်ဗားရှင်းကို အလိုအလျောက်ကိုက်ညှိပြီး တရားဝင် image မှ သီးခြားပတ်ဝန်းကျင် ဖန်တီးနိုင်သည်။ [Guest စနစ်ရွေးချယ်ခြင်း](docs/guide/guest-systems.md)
- **သင်မျှဝေသောအရာကို ထိန်းချုပ်ပါ။** ပုံသေအလုပ်ခွင်နှင့် အတိအလင်းဖွင့်ထားသော ပရောဂျက်ဖိုင်တွဲများကိုသာ မျှဝေပါသည်။ လက်ခံသူ၏ Claude အကောင့်ဝင်ခြင်းအခြေအနေ၊ ဘရောက်ဆာပရိုဖိုင်များနှင့် SSH ကီးများကို အလိုအလျောက် ထည့်သွင်းမည်မဟုတ်ပါ။
- **သင်၏ကွန်ရက်အခြေအနေကိုကြည့်ပါ။** Built-in ကွန်ရက် proxy စီမံခန့်ခွဲမှုသည် သင့်အား စာရင်းသွင်းမှုများကို တင်သွင်းရန်၊ အဆုံးမှတ်များကို ရွေးချယ်ကာ ထွက်ပေါက် IP ကို ​​စစ်ဆေးနိုင်စေပါသည်။ အရေးကြီးသောစစ်ဆေးမှုများမပြီးမချင်း ပတ်ဝန်းကျင်သည် အော့ဖ်လိုင်းဖြစ်နေသည်။ ကွန်ရက်ပရောက်စီကို မရရှိနိုင်ပါက၊ တိုက်ရိုက်ချိတ်ဆက်မှုသို့ ပြန်လှည့်စရာမရှိပါ။
- **နောက်တစ်ကြိမ် ဆက်ရန်။** ကိရိယာများ၊ ဖိုင်များနှင့် အကောင့်ဝင်ခြင်းအခြေအနေသည် virtual disk ပေါ်တွင် ဆက်လက်ရှိနေပါသည်။ ဝင်းဒိုးကိုပိတ်သည့်အခါ နောက်ခံလုပ်ဆောင်စရာများကို ဆက်လက်လုပ်ဆောင်နိုင်သည်။
- **Claude Code အကောင့်များစွာကို စီမံပါ။** အသုံးပြုခွင့်ပမာဏကို ကြည့်ပါ၊ session အသစ်များအတွက် အကောင့်ခွဲဝေပါ၊ တိကျစွာခွင့်ပြုပြီးနောက် အကောင့်ပြောင်း၍ မှတ်တမ်းကို ဆက်သုံးပါ။ [Claude Code](docs/guide/accounts.md)
- **ဖုန်းမှ အလုပ်ဆက်လုပ်ပါ။** Android ဖုန်းကို QR သို့မဟုတ် pairing code ဖြင့် ကွန်ပျူတာနှင့် ချိတ်ဆက်ပါ။ တူညီသော Claude Code စကားဝိုင်းကို ဆက်လုပ်ခြင်း၊ စာပို့ခြင်း၊ ကိရိယာအသုံးပြုမှုကို ခွင့်ပြုခြင်း၊ remote browser နှင့် ကွန်ပျူတာရှိ Claude Desktop ဝင်းဒိုးကို အသုံးပြုခြင်းတို့ ပြုလုပ်နိုင်သည်။
- **Claude Eden ကို cloud ပေါ်တွင် အသုံးပြုပါ။** သင့်လျော်သော Linux x86_64 VPS တွင် Claude Eden ကို တပ်ဆင်ပြီး SSH ဖြင့် ချိတ်ဆက်ပါ။ KVM မလိုပါ။ ဒေတာနှင့် ကွန်ရက်ထွက်ပေါက်သည် server ပေါ်တွင် ရှိသည်။
- **ကိုယ်ပိုင်ကွန်ရက်ဖြင့် ချိတ်ဆက်ပါ။** Claude Eden ထဲတွင် Tailscale ဝင်ပြီး host နှင့် ပတ်ဝန်းကျင်အကြား နှစ်ဖက် SSH ချိတ်ဆက်ပါ။ [Tailscale / SSH](docs/guide/tailscale.md)

## အမြန်စတင်ပါ။

ဤတောင်းဆိုချက်ကို သင်၏ AI အေးဂျင့် (codex၊ dsh၊ workbuddy — Claude Code ဖြစ်နိုင်သည် 😁) ။

```markdown
https://github.com/CarterLeeAlt/Claude-Eden ၏ နောက်ဆုံး source code ကိုရယူပြီး Windows အတွက် build လုပ်ကာ တပ်ဆင်ပေးပါ။ Claude Eden proxy ကို ကျွန်ုပ်၏ local Clash xx node နှင့် xx IP အတွက် သတ်မှတ်ပေးပါ။ ပထမဦးစွာ build လမ်းညွှန်ကိုဖတ်ပြီး တပ်ဆင်မှုအတိုင်းအတာနှင့် ကွန်ရက်ဆက်တင်ကို စစ်ဆေးပါ၊ ထို့နောက် လုပ်ဆောင်ပြီး ရလဒ်ကို အတည်ပြုပါ။
```

သင်လိုအပ်သည်မှာ ယုံကြည်စိတ်ချရသော ကွန်ရက် proxy အဆုံးမှတ်တစ်ခုဖြစ်သည်။ ဤပရောဂျက်သည် မည်သည့်ပရောက်စီဝန်ဆောင်မှုပေးသူကိုမျှ မြှင့်တင်မည်မဟုတ်ပါ။ ဥပမာအားဖြင့် Black Error ဝဘ်ဆိုက်ကို ရှာဖွေခြင်းဖြင့် ပံ့ပိုးပေးသူကို သင်ကိုယ်တိုင် ရှာဖွေနိုင်သည်။

## ဒေါင်းလုဒ်လုပ်ပြီး တပ်ဆင်ပါ။

Claude Eden desktop host သည် Windows 10 22H2 / 11 x64 ဖြစ်ပြီး Windows 10 ကို အဓိကလက်ခံစမ်းသပ်ပလက်ဖောင်းအဖြစ် သတ်မှတ်ထားသည်။ Local guest များမှာ Debian၊ Ubuntu 22.04 နှင့် Windows ဖြစ်သည်။ Windows guest အတွက် Hyper-V ပါသော Windows 11 Pro၊ Enterprise သို့မဟုတ် Education host လိုသည်။ Linux cloud နှင့် backend ကိုလည်း ဆက်လက်ထားရှိသည်။ [Windows](docs/windows.md) · [Linux cloud](docs/linux.md).

1. ထုတ်ဝေထားသော Windows installer ကို [GitHub Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases) တွင် ကြည့်ပါ။ ထုတ်ဝေမှုမရှိပါက [build လမ်းညွှန်](docs/windows.md) ကို လိုက်နာပါ။
2. Windows installer ကိုဖွင့်ပြီး **Claude Eden** ကိုစတင်ပါ။ Server အတွက် [Linux cloud](docs/guide/cloud.md) ကိုကြည့်ပါ။
3. သင့်ကိုယ်ပိုင်ကွန်ရက်ပရောက်စီကို စီစဉ်သတ်မှတ်ရန်၊ ပတ်ဝန်းကျင်ကို စတင်ရန်နှင့် ပရောဂျက်တစ်ခုဖွင့်ရန် အက်ပ်အတွင်း ညွှန်ကြားချက်များကို လိုက်နာပါ။

တပ်ဆင်ဖိုင်တွင် အလုပ်ခွင်နှင့် proxy engine ပါဝင်သည်။ Go၊ Node.js၊ Docker သို့မဟုတ် Clash ကို ကြိုတင်တပ်ဆင်ရန် မလိုပါ။ ပတ်ဝန်းကျင်ဖန်တီးချိန်တွင် guest စနစ်နှင့် သိမ်းဆည်းရာနေရာကို ရွေးပြီး တရားဝင် image နှင့် ကိရိယာများကို ပြင်ဆင်ပါ။ Claude Eden သည် OS လိုင်စင်၊ proxy ဝန်ဆောင်မှု သို့မဟုတ် Claude အကောင့် မပေးပါ။

မူရင်းကုဒ်ကို အများပြည်သူရယူနိုင်သည်။ ထုတ်ဝေထားသော ဗားရှင်းမှတ်စုနှင့် checksum များကို [Releases](https://github.com/CarterLeeAlt/Claude-Eden/releases) တွင် ကြည့်ပါ။

လုပ်ဆောင်ချက်များသည် အသုံးပြုသော build ပေါ်မူတည်သည်။ အများပြည်သူ installer ၏ စွမ်းရည်နှင့် စမ်းသပ်မှုနယ်ပယ်ကို release မှတ်စုတွင် ကြည့်ပါ။

လက်မှတ်ထိုးထားသော Windows ကို ရွေးထားသော proxy ဖြင့် update လုပ်နိုင်သည်။ လက်မှတ်မထိုးထားသော build ကို installer ဖြင့် ကိုယ်တိုင် update လုပ်ပါ။ အရင်ဆုံး အလုပ်ကိုသိမ်းပြီး ရပ်ပါ။ ကိုယ်ရေးဒေတာကို ထိန်းသိမ်းထားသည်။ [အပ်ဒိတ်နှင့် ဖယ်ရှားခြင်း](docs/guide/maintenance.md)

## အဆင့်သုံးဆင့်ဖြင့် စတင်လိုက်ပါ။

### 1. ကွန်ရက်ပရောက်စီကို ရွေးပါ။

ပင်မစာမျက်နှာတွင် 'ကွန်ရက်နှင့် ပရောက်စီကို သတ်မှတ်ပါ'၊ ထို့နောက် 'ရင်းမြစ်ကို ထည့်ပါ' ကို နှိပ်ပါ။ Clash/Mihomo YAML စာရင်းသွင်းမှု သို့မဟုတ် ဒေသတွင်း YAML ဖိုင်ကို တင်သွင်းပြီး 'Nodes' အောက်ရှိ အဆုံးမှတ်ကို ရွေးချယ်ပါ။ ကွန်ရက်ပရောက်စီကို မရရှိနိုင်ပါက၊ သင်သည် 'ဤစာရင်းသွင်းမှုကို လက်ခံဆောင်ရွက်ပေးသည့်ကွန်ရက်မှတစ်ဆင့် ဒေါင်းလုဒ်လုပ်ပါ' သို့မဟုတ် ဒေသတွင်းဖိုင်ကို တိုက်ရိုက်တင်သွင်းနိုင်သည်။ နောက်ပိုင်းတွင်၊ 'ဆက်တင်များ → ကွန်ရက်နှင့် ပရောက်စီ' အောက်တွင် အဆုံးမှတ်များကို စီမံပါ။

### 2. ပတ်ဝန်းကျင်ကို စတင်ပါ။

ပထမဆုံးတွင် guest စနစ် သို့မဟုတ် ပံ့ပိုးပါက အလိုအလျောက်ဗားရှင်းကိုက်ညှိခြင်းနှင့် သိမ်းဆည်းရာကို ရွေးပါ။ Guest ကိုတပ်ဆင်ပြီး ပတ်ဝန်းကျင်စတင်ကာ လိုအပ်သောခွင့်ပြုချက်များကို ပေးပါ။ လုပ်ဆောင်မှုအသေးစိတ်တွင် တိုးတက်မှုနှင့် အမှားများကို ကြည့်နိုင်သည်။ နောက်တစ်ကြိမ်တွင် တူညီသောပတ်ဝန်းကျင်ကို ပြန်သုံးသည်။

### 3. ပရောဂျက်တစ်ခုကိုဖွင့်ပြီး Claude ကိုဖွင့်ပါ။

'Open project' ဖြင့် ဖိုင်တွဲရွေးပါ၊ terminal အသစ်ဖွင့်ပြီး `claude` ကိုစတင်ကာ Workbench browser တွင် အကောင့်ခွင့်ပြုပါ။ မူလအလုပ်ခွင်မှလည်း စတင်နိုင်သည်။ အဆင့်အပြည့်အစုံ — [စတင်လုပ်ဆောင်ခြင်း။](docs/getting-started.md).

## အသုံးမပြုမီ ဤကန့်သတ်ချက်များကို နားလည်ပါ။

- မျှဝေထားသော project တွင် ပြင်ဆင်ခြင်းနှင့် ဖျက်ခြင်းသည် ကွန်ပျူတာဖိုင်များကို တိုက်ရိုက်ထိခိုက်သည်။ Version control သို့မဟုတ် backup ကိုသုံးပါ။ `.git` ကို ဖတ်ရေးနိုင်ပြီး Claude Eden တွင် stage၊ commit နှင့် branch ပြောင်းခြင်း ပြုလုပ်နိုင်သည်။
- Claude Eden configuration တစ်ခုတည်းရှိ project များသည် guest၊ ကိရိယာ၊ အကောင့်နှင့် ဖိုင်စနစ်ကို မျှဝေပြီး အချင်းချင်းသီးခြားမဖြစ်ပါ။ စနစ်ပြောင်းရန် သီးခြားတပ်ဆင်ရပြီး ယခင်ပတ်ဝန်းကျင်ဒေတာကို ထိန်းသိမ်းထားသည်။
- မူလအနေဖြင့် အင်တာနက်အထွက်သည် IPv4 TCP ကို ပံ့ပိုးပြီး DNS သည် တူညီသော proxy ကို သုံးသည်။ အများသုံး UDP၊ IPv6၊ ICMP နှင့် မူရင်းကွန်ပျူတာ သို့မဟုတ် LAN သို့ တိုက်ရိုက်ချိတ်ဆက်မှုကို ကန့်သတ်ထားသည်။ Tailscale ကို ကိုယ်တိုင်ဖွင့်ပါက ကိုယ်ပိုင်ကွန်ရက်ခွင့်ပြုချက်အတိုင်း စက်များကို ချိတ်ဆက်နိုင်သည်။
- ကွန်ရက်စစ်ဆေးမှုများသည် လက်ရှိဖွဲ့စည်းပုံနှင့် နမူနာပုံသက်သေကို ပြသသည်။ အကောင့်တစ်ခုသည် ပလပ်ဖောင်းကန့်သတ်ချက်များကို ရှောင်ရှားနိုင်မည်ဟု အာမခံမပေးနိုင်ပါ။ ၎င်းတို့သည် ပြီးပြည့်စုံသော virtualization လုံခြုံရေးစစ်ဆေးမှုကို အစားထိုးမည်မဟုတ်ပါ။

အသေးစိတ်ကို ကြည့်ပါ။ [ကွန်ရက်နှင့် ဒေတာနယ်နိမိတ်များ](docs/getting-started.md#网络与数据边界).

## မူရင်းနှင့်လိုင်စင်

Claude Eden သည် [Claude-Cage](https://github.com/Lee-xeo/Claude-Cage) နှင့် [agent-vm](https://github.com/sylvinus/agent-vm) ကိုအခြေခံပြီး မူရင်းရင်းမြစ်နှင့် လိုင်စင်များကို ထိန်းသိမ်းထားသည်။

ပရောဂျက်ရဲ့ အဓိက လိုင်စင်ကတော့ [MIT](LICENSE). အစုလိုက်အစည်းလိုက် အစိတ်အပိုင်းများသည် ၎င်းတို့၏ သက်ဆိုင်ရာလိုင်စင်များကို ဆက်လက်ထိန်းသိမ်းထားသည်။ Mihomo ကို GPL-3.0 အောက်တွင် သီးခြားလုပ်ဆောင်နိုင်သော လုပ်ဆောင်ချက်အဖြစ် ဖြန့်ဝေထားသည်။ ကြည့်လည်းကြည့် [NOTICE](NOTICE) · [Third-party လိုင်စင်များ](THIRD_PARTY_LICENSES) · [noVNC](ui/vendor/novnc/LICENSE.txt)。

Claude Eden သည် လွတ်လပ်သောအသိုင်းအဝိုင်းပရောဂျက်တစ်ခုဖြစ်ပြီး Anthropic နှင့် မသက်ဆိုင်ပါ။

## အကိုးအကားများနှင့် အသိအမှတ်ပြုချက်များ

အခြေခံစွမ်းရည်များနှင့် ဒီဇိုင်းကိုးကားချက်များအတွက် အောက်ပါပရောဂျက်များကို ကျေးဇူးတင်ပါသည်။

- [agent-vm](https://github.com/sylvinus/agent-vm): ပရောဂျက်၏ အခြေခံရင်းမြစ်။
- [Lima](https://github.com/lima-vm/lima): Linux virtual machine စီမံခန့်ခွဲမှု။
- [gvisor-tap-vsock](https://github.com/containers/gvisor-tap-vsock): virtual machine ကွန်ရက်ချိတ်ဆက်ခြင်း။
- [sshocker](https://github.com/lima-vm/sshocker) နှင့် [SFTP](https://github.com/pkg/sftp): virtual machine နှင့် host အကြား ဖိုင်မျှဝေခြင်း။
- [noVNC](https://github.com/novnc/noVNC) − ဘရောက်ဆာရှိ အဝေးထိန်းပြသမှုနှင့် အပြန်အလှန်တုံ့ပြန်မှု။
- [Mihomo](https://github.com/MetaCubeX/mihomo) − တပ်ဆင်ထားသော ကွန်ရက် ပရောက်စီ အူတိုင်။
- [code-server](https://github.com/coder/code-server) - ဘရောက်ဆာအခြေခံကုဒ်တည်းဖြတ်သူ။
- [AIO Sandbox](https://github.com/agent-infra/sandbox): လုပ်ငန်းခွင်ပတ်ဝန်းကျင်နှင့် အပြန်အလှန်အကျိုးပြုမှုဒီဇိုင်းအတွက် ကိုးကားချက်များ။
- [claude-switcher](https://github.com/YOURSJEYO/claude-switcher) နှင့် [Claude-Guardian](https://github.com/DUNHKpcc/Claude-Guardian): ကွန်ရက်စစ်ဆေးမှုများနှင့် လုံခြုံရေးဆိုင်ရာ စစ်ဆေးမှုများအတွက် ကိုးကားချက်များ။
- [claude-post-ban-cleanup](https://github.com/l2461090/claude-post-ban-cleanup): တိကျသောစာရင်းစစ်ဆေးမှု၊ ဒေတာကာကွယ်မှုနှင့် ပြန်လည်ရယူနိုင်သော cache ရှင်းလင်းမှုကို ကိုးကားကာ Claude Eden တွင် သီးခြားအကောင်အထည်ဖော်ထားသည်။
